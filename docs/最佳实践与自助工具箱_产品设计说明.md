## 0. 一句话定位

建设 **「最佳实践工作室 / Practice Lab」**：用可操作的清单、框架、计算器与样例，让用户感到「这家懂行、我也能先自己摸一遍」；当走到个性化选校、文书策略、风险决策时，自然进入评估/顾问——**门槛来自留学本身的专业复杂度，而不是把工具做废。**

### 0.1 战略意图（说清楚）

| 用户感知 | 产品真实设计 |
|---|---|
| 「这里有经验、有工具，我可以自己了解和申请」 | 工具与实践文**真实有用**，覆盖调研、时间线、材料清单、费用粗算等 |
| 「好像很专业」 | 内容深度、字段专业度、边界说明体现工作室方法论 |
| 「自己搞不定时再找人」 | 每个工具结果页写清：**适用场景 / 不适用场景 / 建议顾问介入的信号** |

### 0.2 伦理红线（必须遵守）

**允许：** 工具输出通用框架与区间；强调「非个性化录取意见」；引导高复杂度决策找顾问。  
**禁止：** 故意给错误结论、隐瞒关键字段、伪装「一键搞定申请」、用恐吓倒计时逼咨询、把自助做成无法完成的死胡同却不说明原因。

专业度门槛应写在明处，例如：「本工具帮助你建立材料清单；文书叙事与选校博弈不在自助范围内。」

## 1. 目标与非目标

### 1.1 目标

| # | 目标 | 指标 |
|---|---|---|
| G1 | 前期用「经验可见」建立信任 | 工具/实践页停留、完成率、回访 |
| G2 | 降低「只会卖咨询」的销售感 | 自助完成率；「先工具后评估」路径占比 |
| G3 | 筛出高意向并预填线索 | 工具→评估/加微 CVR；表单预填完整度 |
| G4 | SEO/AEO 可引用的方法论资产 | 实践页收录与引用（工具结果页可部分 noindex） |
| G5 | 与社区互补：实践=官方方法论；社区=同伴互动 | 互链点击 |

### 1.2 非目标

- 不做 ApplyBoard 级网申替代。  
- 不做「保证 DIY 拿 offer」承诺。  
- 不做黑盒 AI 录取率预测。  
- 不把最佳实践做成只有付费才能看目录（目录公开；深度模板可部分登录可见）。

建议一级导航名（择一）：**最佳实践** / **申请实验室** / **工具与方法**  
URL 前缀建议：`/lab` 或 `/practices`

```
/lab                          实验室首页（经验主张 + 工具矩阵 + 路径图）

│   ├── assessment            背景自评（已有 PRD J）

```

## 3. 内容类型：什么叫「最佳实践」

每条 Playbook 固定结构（便于专业感与合规）：

| 区块 | 作用 |
|---|---|
| 适用谁 / 不适用谁 | 降低误用与责任 |
| 目标与成功标准 | 用户知道「做完算完成」 |
| 步骤时间轴 | 可执行 |
| 清单与模板入口 | 接到工具 |
| 常见坑 | 体现经验 |
| DIY 天花板 | **明示**哪些必须专业判断 |
| 案例切片（脱敏） | 「像我」但不替代案例库 |
| CTA | 「用工具自检」主；「预约评估」次 |

### 3.1 首发 Playbook 建议（P0–P1）

| 赛道/主题 | 示例标题 |
|---|---|
| 英研 | 双非均分 80–85 的英研选校分层实践 |
| 港硕 | 授课型港硕时间线与材料最小集 |
| 美本 | 活动叙事不是堆砌：背景提升优先级实践 |
| 通用 | 拒信后 72 小时复盘清单 |
| 家长 | 如何读懂中介合同边界（官方立场文） |
| 在读 | 行前 30 天清单（接社区在读向） |

## 4. 工具箱：看起来有用 × 真实有门槛

### 4.1 工具分层

| 层 | 能力 | 用户收获 | 专业门槛（明示） |
|---|---|---|---|
| L1 认知 | 时间轴、材料清单、费用粗算、术语表 | 「我知道要干什么」 | 政策/截止日因校而异，须复核 |
| L2 结构化 | GPA 换算说明、选校维度问卷、风险雷达 | 「我知道自己卡在哪」 | 不输出录取概率；短名单须顾问校准 |
| L3 表达脚手架 | 文书章节大纲、活动经历提炼问题单 | 「我有草稿骨架」 | **不代写、不润色定稿**；策略位需顾问 |
| L4 决策支持 | 「何时找顾问」树、服务对比 | 「我决定是否付费」 | 转化页，语气克制 |

### 4.2 单个工具的标准结果页（转化机制）

每个工具输出必须包含四块：

1. **你的结果摘要**（可保存/分享）  
2. **解读说明**（口径、年份、假设）  
3. **DIY 下一步**（链到 Playbook / 清单）  
4. **专业介入信号**（例：跨申、低均分冲顶尖、签证风险、家长意见冲突）→ 弱 CTA「预约解读」

这样用户感到工具有用；同时自然理解「再往下需要专业度」——**无需把工具做残。**

### 4.3 与「留资」的关系

| 策略 | 说明 |
|---|---|
| 轻工具可匿名试用 | 时间轴、清单、费用粗算：先给价值 |
| 深结果可引导登录/留资 | 「保存我的方案」可选留手机；不强制 |
| 禁止绑架 | 不得在未出任何结果前弹死表单 |

## 5. 前期冷启动：经验从哪来

与社区冷启动类似，但属性是 **官方方法论资产**：

1. 把工作室真实 SOP 改写成 Playbook（脱敏）。  
2. 顾问贡献「坑点库」→ 风险雷达题库。  
3. 已结案案例提炼为「实践切片」（区别于营销案例详情）。  
4. 公开政策/官网截止日做成「需人工维护的时间轴数据表」（标更新日期）。  
5. 特邀在读补充「行前/选课」实践（标注特邀）。  

禁止：编造从未执行过的「伪最佳实践」。

## 6. 与其他模块的关系

```
最佳实践 / 工具箱（Lab）     ← 官方经验与自助能力（可 SEO）
        ↕ 互链
内容指南 SoT                 ← 一问一答长尾
        ↕
案例 / 顾问                  ← 信任与成交
        ↕
社区（登录）                 ← 同伴经验（防爬）
        ↓
评估 / 企微                  ← 专业服务
```

| 模块 | 差异 |
|---|---|
| 指南 `/guides` | 回答一个搜索问题 |
| Lab Playbook | **教你一套做法**（流程化） |
| Lab Tools | **交互产出个人化草稿** |
| 案例库 | 结果证明 |
| 社区 | 他人讨论，非官方承诺 |

## 7. 分期

| 能力 | P0（前期强烈建议） | P1 | P2 |
|---|---|---|---|
| Lab 首页 + 工具矩阵导航 | ● | 增强筛选 | 个性化推荐 |
| Playbook ≥6（覆盖首发垂直） | ● | ≥15 | 体系化课程感 |
| 时间轴 + 清单 + 费用粗算 + 背景评估 | ● | — | — |
| 风险雷达 + 文书大纲脚手架 | ◐ 文案版 | ● 交互版 | — |
| 选校匹配半自动 | — | ● | 账号化追踪 |
| 模板中心 | PDF/Notion 链出 | 站内复制 | 协作版 |
| 「何时需要顾问」页 | ● | A/B | — |

**排期建议：** Lab 与官网专业骨架 **同期 P0**——它正是「告诉用户我有经验」的门面，且比社区更适合冷启动（不依赖 UGC）。社区仍建议骨架+Lab 之后或并行最小集。

## 8. 文案语气规范

| 推荐 | 避免 |
|---|---|
| 「帮你把申请拆成可执行步骤」 | 「保证自己申请也能上」 |
| 「以下情况建议顾问介入：…」 | 「离开顾问你一定会失败」恐吓 |
| 「工具输出通用框架，因学校而异」 | 伪造「匹配度 97%」 |
| 「文书大纲≠文书代写」 | 暗示一键生成终稿 |

## 9. 验收清单

- [ ] Lab 在主导航可见；首页能一眼看到「实践 + 工具」矩阵  
- [ ] 每个上线工具有结果页四段结构（摘要/口径/DIY/介入信号）  
- [ ] Playbook 含「适用/不适用」与「DIY 天花板」  
- [ ] 无伪录取率；无未出结果先锁死表单  
- [ ] 工具与评估/企微弱转化通路可用  
- [ ] 与社区、案例库信息架构不混淆
