## 1. 授权模板（签署前必填）

请学员/家长书面确认：

1. 同意青藤国际在官网、社媒、物料中使用脱敏后的申请背景与录取结果。
2. 同意展示内容范围：□ 院校 □ 专业 □ 本科背景层级 □ 均分区间 □ 文书策略摘要 □ 导师化名。
3. 禁止展示：真实姓名、证件号、原件成绩单、聊天原文、未经同意的照片。
4. 授权期限：自签署日起 ___ 年；可随时书面撤回。
5. 签署人：□ 本人 □ 监护人；联系方式：__________；日期：__________。

签署件存档路径：运营盘 / `授权/案例/{slug}/`；Directus `cases.authorized = true` 且上传扫描件或备注授权编号。

## 2. 脱敏规则

| 字段 | 规则 |
|---|---|
| 姓名 | 姓 + 同学 / 化名 |
| 本科院校 | 可用「985/双非/国际部」层级；特定校名需单独授权 |
| 均分 / GPA | 区间或一位小数，禁止完整成绩单截图 |
| 文书原文 | 禁止全文；仅策略摘要 |
| 联系方式 | 一律不展示 |

## 3. 24 小时下架流程

1. 收到撤回/投诉（邮件 `supervision@qingteng.com` 或企微）→ 15 分钟内确认工单。
2. Directus 将对应 case `status=archived` 或 `authorized=false`，触发 revalidate。
3. 同步下架社媒转载；站内 24 小时内不可再被搜索/sitemap 收录。
4. 工单关闭条件：前台 404/隐藏 + 备份库备注撤回时间。

## 4. 责任人

- 运营：授权收集与复审日期
- 顾问：事实核对
- 技术：字段与下架生效
