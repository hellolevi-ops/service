## 1. 文档目的与阅读对象

### 1.1 目的

定义「做什么生意、为谁创造什么价值、价值如何流动、组织如何协作、能力如何分期建设」，作为产品、运营、顾问、技术对齐的**业务蓝图**。技术选型见技术架构文档；页面与字段级需求见 PRD。

### 1.2 读者

| 角色 | 关注点 |
|---|---|
| 创始人 / 工作室负责人 | 商业模式、飞轮、分期投入 |
| 运营 / 增长 | 获客通道、内容真相源、多平台分发 |
| 顾问 / 销售 | 线索分级、SLA、服务交付边界 |
| 产品 / 设计 | 能力地图、旅程、系统边界 |
| 技术 | 业务能力与系统域映射 |

### 1.3 设计原则

1. **官网是增长资产，不是电子名片**——真相源 + 飞轮 + 转化出口。  
2. **对标专业能力，克制体量**——不做 ApplyBoard 级网申中台。  
3. **双飞轮驱动**：站外收录/分发 ↔ 站内留存/转化。  
4. **服务三线并存，成交漏斗统一**——精品 / 全流程 / 垂直共用线索池。  
5. **合规优先于话术**——不承诺无法核验的录取结果。

## 2. 业务愿景与战略定位

### 2.1 愿景

成为大陆家庭「想留学时第一个被搜到、被 AI 提到、被同学安利，并且逛起来越来越清晰」的留学工作室入口。

### 2.2 一句话定位

**搜索与 AI 把人送进来 → 站内飞轮让人变清晰 → 评估把清晰变成线索 → 顾问把线索变成签约 → 案例原子再喂回站外。**

### 2.3 战略选择（做什么 / 不做什么）

| 选择 | 说明 |
|---|---|
| 做 | 内容获客、信任证明、评估留资、顾问交付、多平台切片分发 |
| 做深 | 美本 / 英研 / 港新 / 低龄 / 艺术五条垂直 |
| 暂缓 | 全球项目库网申、学员门户、多城市分站、语培自营 LMS |
| 永不做（品牌红线） | 包录话术、恐吓倒计时、伪造热度、出售线索给第三方 |

### 2.4 价值主张画布（简版）

| 侧 | 内容 |
|---|---|
| 客户群 | 学生 + 家长（决策常共同完成） |
| 痛点 | 信息不对称、怕踩坑、怕销售话术、怕过程失控 |
| 获益 | 更快搞清适不适合、看见像我的路径、有人可约诊 |
| 渠道 | 百度/谷歌、豆包等 AI、小红书/抖音、微信转介绍 |
| 收入 | 精品咨询费、全流程服务费、模块加购（文书/面试等） |
| 成本 | 顾问人力、内容生产、投放、工具订阅、合规 |

## 3. 商业模式

### 3.1 收入结构

```
收入
├── 精品线（高客单）——策略/文书/背景/面试包
├── 全流程线（主流量）——选校到签证行前
├── 模块加购 —— 单文书、签证加项、行前加项（可选）
└── （未来）公开课/资料包付费、院校合作返佣（需单独合规评估）
```

MVP 默认：**评估免费，签约收费**；官网可不公开展示精确总价，但必须展示计费逻辑或区间（见 PRD）。

### 3.2 成本结构（业务视角）

| 成本类型 | 典型项 | 飞轮关系 |
|---|---|---|
| 变动 | 顾问跟进时间、签约交付工时 | 线索质量越高，单位成本越低 |
| 半固定 | 内容写作、短视频拍摄 | 内容资产可复利 |
| 固定 | 域名托管、工具、基础投放测试预算 | 技术架构控制在可维护范围 |

### 3.3 单位经济模型（逻辑，非财务预测）

```
获客成本 CAC
  =（投放 + 内容分摊 + 工具）/ MQL 或 SQL

贡献毛利
  = 客单 × 毛利率 − 交付变动成本

健康条件（业务目标）
  LTV / CAC ≥ 3（签约后按服务周期计）
  内容/自然占比提升 → CAC 下降
```

官网北极星仍以 **MQL + 飞轮健康度** 为准；财务指标由经营周会另表跟踪。

## 6. 组织与角色架构

### 6.1 初创期最小编制（建议）

| 角色 | 人数（参考） | 业务职责 |
|---|---|---|
| 负责人 | 1 | 定价、红线、重大案例审核、渠道策略 |
| 顾问 | 1–3 | 首咨、分级、签约、交付执行 |
| 内容/运营 | 0.5–1（可兼职） | SoT、原子、平台发布、收录提交 |
| 设计/开发 | 外包或兼职 | 按技术架构交付 |

### 6.2 RACI（核心流程）

| 活动 | 负责人 | 顾问 | 运营 | 技术 |
|---|---|---|---|---|
| 定价与产品边界 | A | C | I | I |
| SoT 发布 | A | C | R | C |
| 线索 15 分钟响应 | A | R | I | C |
| 案例上架授权 | A | R | C | I |
| 投放落地页一致性 | A | C | R | C |
| 隐私与免责文本 | A | I | C | C |
| 指标周报 | A | C | R | C |

R=执行 A=问责 C=协商 I=知会

### 6.3 值班与 SLA（业务规则）

| 规则 | 标准 |
|---|---|
| 工作时间首触 | ≤ 15 分钟 |
| 非工作时间 | 自动回复 + 次一工作时段前联系 + 引导加微信 |
| 无效线索关闭 | 3 次未接通或明确无意向，标记无效并停止骚扰 |
| 案例下架 | 授权撤回 24 小时内前台不可见 |

## 7. 客户分层与产品架构

### 7.1 客户分层

| 分层 | 特征 | 主推产品 | 官网路径 |
|---|---|---|---|
| 冲刺型学生/家庭 | 冲顶尖、愿付高客单、要策略 | 精品线 | /services/premium |
| 省心型家庭 | 要全包、怕踩坑、要节点透明 | 全流程线 | /services/full-cycle |
| 赛道明确型 | 已定美本/英研/港新等 | 对应垂直 + 上两线之一 | /tracks/* |
| 观望型 | 只查费用条件 | 内容飞轮养熟 | /guides/* → 评估 |

### 7.2 产品架构（业务对象）

```
产品组合
├── 精品咨询产品包
│   ├── 策略规划
│   ├── 文书辅导
│   ├── 背景规划
│   └── 面试辅导
├── 全流程服务产品包
│   ├── 评估选校
│   ├── 材料与递交
│   ├── 结果跟进
│   ├── 签证
│   └── 行前
└── 垂直解决方案（包装层，非独立 SKU 也可）
    ├── 美本 / 英研 / 港新 / 低龄 / 艺术
    └── 落地页 + 话术 + 案例池 + 顾问匹配规则
```

垂直是**获客与话术包装**；SKU 仍归并到精品或全流程（或混合），避免后台 SKU 爆炸。

### 7.3 定价与报价业务规则

1. 评估免费，不绑消费。  
2. 官网上展示「区间」或「评估后报价 + 计费因子」。  
3. 报价单必须列：包含项、不包含项、有效期、退费原则摘要。  
4. 禁止口头「内部名额/包录」进入任何对外话术库。

## 8. 端到端业务流

### 8.1 主价值链（Level 1）

```
发现 → 理解 → 信任 → 互动飞轮 → 留资 → 首咨 → 方案报价
  → 签约 → 交付 → 结果沉淀 → 内容复利 → 再获客
```

### 8.2 获客到线索（Level 2）

```
渠道触达
  → 意图匹配着陆（垂直/指南/广告页一致）
  → 答案块建立价值
  → 下一站 / 像我案例（可选多跳）
  → 短表单或预约或微信/电话
  → 线索入库（含 UTM、track、同意记录）
  → 通知顾问
```

### 8.3 线索到签约（Level 2）

```
新线索
  → 触达（电话/企微）
  → 资格判断（时间窗口、预算、真实性）
  → 标 MQL / SQL / 无效 / 回收
  → SQL：诊断会（45–60min）
  → 推荐精品 or 全流程 or 暂缓养熟
  → 报价与异议处理
  → 签约与收款（线下/现有工具）
  → 交接交付负责人（可同一人）
```

### 8.4 交付到复利（Level 2）

```
开工
  → 节点执行（按 SOP）
  → 家长同步（周报/企微）
  → 结果（offer/签证等）
  → 授权评估
  → 案例上架 + 原子切片
  → 投放/社媒/SEO 再利用
```

### 8.5 状态机：线索

```
新提交 → 已联系 → MQL → SQL → 已签约
                ↘ 无效
                ↘ 回收（养熟，定期触达）
```

### 8.6 状态机：内容

```
草稿 → 待审 → 已发布 → 需复审（过期） → 更新发布 / 下架
```

## 9. 双飞轮业务设计

### 9.1 站内飞轮（留存→转化）

| 环节 | 业务动作 | 成功表现 |
|---|---|---|
| 即时收获 | 每篇必有答案块 | 跳出率下降 |
| 进展感 | 清单/测验（P1） | 回访与完成率 |
| 连续消费 | 下一站推荐 | 页深 ≥ 2.5 |
| 自我对照 | 像我案例 | 评估点击上升 |
| 出口 | 评估 CTA 随清晰度加权 | CVR 提升 |

业务禁令：不得用虚假紧迫感驱动出口。

### 9.2 站外飞轮（获客→资产）

| 环节 | 业务动作 | 成功表现 |
|---|---|---|
| 生产 SoT | 官网先写完整页 | 可被收录/引用 |
| 拆原子 | 一问一答/案例切片 | 周产原子 ≥5 |
| 分发 | 小红书/抖音/视频号 | UTM 会话可见 |
| 回流 | 主页/搜品牌/短链 | MQL 带社媒来源 |
| 对账 | 热门问句回写 FAQ | AI/搜索一致性 |
| 收录运营 | 站长平台 + AI 探测 | 索引与引用提升 |

### 9.3 飞轮治理会议（建议）

| 会议 | 频率 | 议题 |
|---|---|---|
| 增长站会 | 周 | MQL、页深、下一站 CTR、渠道结构 |
| 内容评审 | 双周 | SoT 质量、过期页、原子库存 |
| 合规抽检 | 月 | 案例授权、广告语、隐私同意抽检 |

## 10. 渠道业务架构

### 10.1 渠道矩阵

| 渠道 | 业务目标 | 着陆策略 | 主转化 |
|---|---|---|---|
| 百度/谷歌自然 | 长尾低成本 | 指南/垂直 | 表单/微信 |
| SEM | 抢高意图 | 与广告一致的垂直页 | 短表单 |
| AI 助手 | 被引用 | 答案块页 | 评估 |
| 小红书 | 种草信任 | 案例/避坑 SoT | 搜品牌或链 |
| 抖音/视频号 | 注意力 | 聚合或案例 | 主页+企微 |
| 转介绍 | 高 SQL | 专属感谢/顾问页 | 预约 |
| 企微私域 | 养熟成交 | 文章链接 | 预约/报价 |

### 10.2 渠道所有权

- 运营：内容渠道与 SEO/AEO、社媒日历。  
- 负责人：付费投放预算与 ROI。  
- 顾问：转介绍维护与私域成交话术（经审核）。

| 访客会话 | 来源、落地页、页深、停留 |

| 内容原子 | 来源 SoT、平台适配文案 |
| 顾问 | 方向、是否接评估 |

### 11.2 指标树

```
经营结果：签约数、营收、客单
    ↑
转化：CVR、预约率、出席率、MQL→SQL→签约
    ↑
飞轮：页深、回访、下一站 CTR、微任务完成
    ↑
获客：会话、自然占比、AI 占比、社媒占比
    ↑
供给：SoT 产量、原子产量、案例库存、索引覆盖
```

双北极星：见 PRD 3.3。

## 12. 合规与风险业务架构

### 12.1 合规控制点

| 控制点 | 规则 |
|---|---|
| 留资 | 同意勾选 + 政策版本记录 |
| 宣传 | 无包录；案例可下架；数字带年份 |
| 数据 | 最小必要；不售卖线索 |
| 授权 | 无授权不上架；撤回即下架 |
