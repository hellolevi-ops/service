## 0. 给执行 Agent 的强制规则

1. **禁止凭记忆写「感觉差不多」**：必须用浏览器（或可抓取公开页）**逐个打开**下列平台的关键页面，记录真实导航、模块、转化路径、服务分层、内容形态。  
2. 每个平台至少覆盖：**首页、服务/产品、国家或院校相关、案例/成功故事、顾问/团队、费用或套餐（若有）、预约/留资、内容/资讯、App 或小程序入口（若有）、页脚信任/资质**。  
3. 输出必须区分：**事实摘录（页面上见到的）** vs **推断（业务逻辑解读）**。  
4. 调研完成前，**不要**急着写最终 PRD；先出调研报告，再基于报告重设计。  
5. 重设计时默认客群是 **中国大陆学生 + 家长**；所有信息架构、信任设计、转化通道、视觉语气、社媒入口必须优先大陆习惯（微信、手机优先、案例与排名焦虑、家长决策权、客服即时性等）。  
6. 「专业」≠「照搬巨头全量功能」。专业体现在：**服务深度表达、信任体系、决策路径完整、运营后台闭环、中国区转化细节**；初创可分期，但 **PRD 的能力蓝图要对齐头部，而不是只写一个简陋落地页**。  
7. 旧 PRD 中的飞轮 / SEO / AEO / 小红书抖音可保留为增长层，但必须挂在更完整的业务与产品骨架之上，不能替代核心服务产品力。

## 2. 单平台调研模板（每个平台一份）

对每个平台复制填写：

### 2.1 基本面

- 官网 URL、语言/地区站、是否有 App/小程序/企微  
- 商业模式判断：中介佣金 / 咨询费 / 平台撮合 / 路径项目 / 内容获客  
- 主客群与主推国家/阶段  

### 2.2 信息架构（如实记录导航）

- 一级导航列表  
- 二级关键入口  
- 页脚能力地图  

### 2.3 产品与服务逻辑

- 服务分层（例如：规划 / 申请 / 签证 / 背景提升 / 语培 / 行前 / 就业）  
- 套餐或产品如何命名与区隔  
- 「免费」与「付费」边界如何呈现  
- 是否有院校库 / 项目搜索 / 选校工具 / 测评  

### 2.4 信任与转化

- 信任模块：资质、数据、案例、顾问、媒体、合作院校  
- 主 CTA / 次 CTA  
- 留资字段与多通道（电话、表单、微信、在线客服、预约）  
- 是否强销售感 vs 顾问专业感  

### 2.5 内容与增长

- 内容类型（攻略、政策、排名、活动、直播）  
- SEO 痕迹、地区词、长尾  
- 社媒入口（尤其微信/视频号/小红书/抖音）  

### 2.6 中国区适配观察（海外站也要写「若服务中国用户会缺什么」）

- 手机体验、加载、弹层  
- 家长视角信息是否够  
- 是否解释费用构成、时间线、风险  

### 2.7 可借鉴 / 不可照搬（对本项目）

- 可借鉴的 5 点（具体到模块）  
- 不可照搬的 3 点（体量/合规/商业模式原因）

## 3. 横向对比矩阵（调研报告必含）

1. **服务生命周期覆盖**（规划→背景→考试→申请→签证→行前→境外→就业）

5. **中国用户友好度**（微信生态、手机、家长、城市站、客服）  
6. **内容引擎**（产量形态、是否可支撑 SEO/AI 引用）  

并给出：**头部共性「专业感」从何而来**（至少 10 条可观察特征，附截图或文字证据）。

## 4. 中国区用户洞察（专章，必须单独成章）

基于竞品观察 + 已知大陆留学决策习惯，系统写清：

| 维度 | 要求写到的内容 |
|---|---|
| 决策单元 | 学生 vs 家长谁拍板；不同阶段差异 |
| 信息偏好 | 排名、录取案例「像我」、费用总价、时间表、避坑 |
| 渠道习惯 | 百度/抖音/小红书/知乎/微信群/转介绍权重 |
| 信任触发 | 资质、真人顾问、过程透明、合同边界、差评焦虑 |
| 转化习惯 | 先加微信再深聊；反感强销售；要「评估」而非「下单」 |
| 审美与语气 | 避免土促销；也避免纯欧美冷淡风；专业、稳、有温度 |
| 设备 | 微信内置浏览器、移动优先 |
| 合规敏感 | 包录、内部名额、虚假成功率 |

输出：**中国区官网体验原则 15 条**（可直接指导设计与 PRD）。

## 5. 重设计原则（写新 PRD 时）

1. **能力蓝图对齐头部**，用「完整业务能力地图」描述平台应有能力。  
2. **交付分期诚实**：P0/P1/P2 标明「对标模块」与「本期实现深度」，避免把蓝图缩成低端单页。  
3. 产品叙事建议采用「工作室精品 + 全流程交付」双轮，但官网呈现必须有：  
   - 国家/项目深度内容  
   - 案例体系（可筛选、可对照）  
   - 顾问体系（可指定）  
   - 服务流程可视化  
   - 费用与边界透明  
   - 即时咨询（微信/企微）  
   - 活动/公开课  
   - 选校/评估工具（哪怕先半自动）  
4. 增长飞轮（SEO/AEO/短视频）是加速器，**不能替代**服务产品主骨架。  
5. 明确与前途/金吉列的差异化：小而深、顾问可见、执行透明、垂直赛道专家感——用专业模块证明，而不是用「我们比巨头便宜」证明。
