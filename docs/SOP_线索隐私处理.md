# 线索删除 / 匿名化 / 授权撤回 SOP（人工）

| 项目 | 内容 |
|---|---|
| 版本 | v0.1 |
| 日期 | 2026-09-28 |
| 负责人 | 运营 + 技术 + 法务 |

## 1. 受理入口

- 监督邮箱：见站点 `SITE.complaintEmail`
- 工单字段：申请人身份、手机号后四位、处理诉求（查阅 / 更正 / 删除 / 撤回同意）、关联 leadId（如有）

## 2. 身份核验

1. 核对手动提供的手机号与库内线索是否匹配。
2. 低龄线索须监护人确认。
3. 无法核验时不得执行删除，仅可回复需补充材料。

## 3. 处理动作

| 诉求 | 动作 | 时限 |
|---|---|---|
| 查阅 | 导出脱敏摘要（姓名、方向、提交时间、状态） | 15 工作日 |
| 更正 | 更新 leads 对应字段并记 lead_notes | 15 工作日 |
| 删除 | 硬删或匿名化（姓名→已删除用户，手机→hash，清空微信） | 15 工作日 |
| 撤回同意 | 标记 status=`invalid`，invalid_reason=`consent_withdrawn`，停止外呼/营销 | 即时停止外联 |

## 4. 记录

每次处理在 `lead_notes` 记一条：操作人、时间、动作、依据工单号。邮件回复留存至运营共享盘。

## 5. 例外

司法/监管协查、未结清合同争议期间可依法延期删除，须法务书面确认并告知申请人。
