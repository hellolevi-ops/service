## 2. Seed 定位

- `SEED_VERSION` / `SEED_UPDATED_AT`：见 `src/content/seed.ts` 导出常量。
- 用途：本地开发、Directus 不可用时的灾备回退、sitemap/llms 静态兜底。
- 规则：生产运营修改走 Directus；seed 仅随代码发版更新。

## 3. 迁移顺序建议

1. 扩展 Directus：cases / advisors / events / tracks / playbooks / settings。
2. 页面改读 `@/content`（已对文章生效），案例/顾问/活动陆续切换。
3. 下线页面内硬编码 boyan 展示数据；boyan 仅保留未迁移模块。
4. sitemap、llms、推荐模块统一走 `@/content`。

## 4. 字段治理最低要求

每条可发布内容需具备：`status`、`published_at`、`updated_at`、`review_at`（复审）、归档状态。
