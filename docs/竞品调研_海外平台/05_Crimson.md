## 2.7 可借鉴 5 / 不可照搬 3

### 可借鉴
1. **结果证明墙**（分校录取枚数 + 对比普通录取率）
2. **顾问背景透明**（G5/藤校背景团队叙事）
3. **「免费咨询」入口**清晰与服务深度分层
4. **低龄预备产品线**拉长生命周期
5. **中文微信入口**落地转化

### 不可照搬
1. 1700+ 藤校 offer 量级宣称
2. 「7x / 98%」类对比营销（合规与证明成本）
3. 纯顶尖英美定位（与更广客群项目可能冲突）
