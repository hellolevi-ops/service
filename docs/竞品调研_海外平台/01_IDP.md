## 2.3 产品与服务逻辑

### 服务分层（【事实】页面模块）
1. **升学咨询/申请**：专属升学顾问；Enquire now 表单；「免费海外升学咨询」
2. **课程搜索**：Subject + 教育程度 + 留学地点；热门：Law / Medicine / Psychology / Dental
3. **FastLane**：几秒钟内即时获得梦想大学快速回覆；申请前资格检查
4. **奖学金**：超过 5,100 个奖学金机会；370 多间顶尖院校
5. **成本计算机**：留学预算工具
6. **签证协助**：留学签证申请协助
7. **学生支援服务**：健康保险、汇款、住宿、银行、电话卡
8. **IELTS**：官方主办机构；预约考试；备试资源
9. **活动**：IDP Singapore Events；最新活动报名
10. **社区**：IDP Community；Chat with student ambassador

### 免费 vs 付费（【事实】）
- 「零佣金服务」「不会向您收取升学服务费用」「face-to-face … free of charge」
- 未见咨询费价目表

### 工具（【事实】）
- 课程搜索、FastLane、奖学金搜索、成本计算机、IDP Live App、办事处定位器

## 2.7 可借鉴 5 / 不可照搬 3

### 可借鉴
1. **生命周期导航**：申请步骤→课程→雅思→支援→活动一条链
2. **「免费咨询」边界写清** + 院校合作背书
3. **工具层**：FastLane / 成本计算 / 奖学金 / App 追踪
4. **办事处定位器**作本地信任入口
5. **学生社区 + ambassador 聊天**作弱销售信任

### 不可照搬
1. IELTS 官方主办方身份与考试流量（合规/牌照不可复制）
2. 210+ 办公室 / 50 万学生量级叙事（初创不可对等宣称）
3. 纯佣金「对学生零收费」全球模式（中国精品咨询常为收费服务，商业模式不同）
