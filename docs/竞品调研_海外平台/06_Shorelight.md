## 2.7 可借鉴 5 / 不可照搬 3

### 可借鉴
1. **School match quiz** 低摩擦入口
2. **院校卡展示排名+学费+国际生比例**决策信息密度
3. **Research→Career 全链路服务图**
4. **对学生「无额外费用」写清**
5. **Counselors 渠道专区**（B2B2C）

### 不可照搬
1. 与美国大学独家/深度合作运营模式
2. 仅美国目的地定位
3. Career Premium 等增值合同体系复杂度
