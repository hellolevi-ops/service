# 宣传声明审批表（模板）

| 字段 | 填写说明 |
|---|---|
| 文案原文 | 拟上线句子（含数字/身份） |
| 出现位置 | 首页 / 服务页 / 案例 / 活动 / 社媒 |
| 声明类型 | 数字成果 / 身份资质 / 服务承诺 / 退费 |
| 证据附件 | 统计表、合同条款、人员授权书编号 |
| 统计口径 | 样本范围、周期、分子分母定义 |
| 审批人 | 业务负责人 + 法务 |
| 生效日期 | YYYY-MM-DD |
| 复审日期 | 最长不超过 12 个月 |
| 状态 | 草稿 / 已批准 / 已下线 / 核验中 |

## 当前站点处理原则（2026-09-28）

- 未完成证据核验的强数字（如具体录取率、累计 Top50 数量）**不得**上首页主视觉。
- 未核验的「教育部资质」「前招生官」等身份表述改用过程与交付物表述。
- 「拒录全额退费」仅出现在已审批合同摘要中；营销页改写为「退费与服务边界以签约合同为准」。
