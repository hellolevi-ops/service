## 1. 文档信息与编写目的

### 1.1 编写目的

本文档是留学工作室官网的**能力蓝图与分期交付合同**。它回答四件事：

1. 相对前途出国、启德、金吉列、啄木鸟、无忧，以及 IDP、ApplyBoard、Edvoy、Crimson、Shorelight、Studyportals 等头部，**专业表达应对齐哪些可观察能力**（事实依据见调研报告，不凭感觉扩 scope）。  
2. 相对连锁巨头，本产品如何用**小而深、顾问可见、执行透明、垂直专家感**形成差异，而不是用「更便宜」或单页电子名片证明专业。  
3. 官网必须呈现的服务骨架（国家/项目、案例、顾问、流程费用、即时咨询、活动、工具）与增长层（SEO/AEO/短视频）如何分层——**增长是加速器，不是骨架替代品**。  
4. P0 / P1 / P2 各自做到什么深度，验收什么，明确不做什么。

阅读对象：创始人、产品、设计、运营、顾问负责人、技术负责人。业务价值流与组织协作见业务架构 v2；字段级实现可与技术架构对齐。

### 1.2 与 v1.1 的本质升级

| 维度 | v1.1 问题 | v2.0 纠正 |
|---|---|---|
| 文档重心 | 飞轮/GEO/短视频篇幅压过服务产品 | 先完整服务能力地图，增长层挂在骨架上 |
| 专业感定义 | 易被读成「漂亮落地页 + 内容飞轮」 | 对齐调研报告六层结构 + ≥10 条可观察专业特征 |
| 分期写法 | MVP 清单易被误读为蓝图上限 | 蓝图表格含「对标模块」与「本期实现深度」两列 |
| 对标依据 | 记忆级竞品摘要 | 绑定 2026-09-28 实访报告与源笔记 |
| 中国区 | 分散在各章 | 15 条原则逐条映射到模块与验收 |

### 1.3 范围内（In Scope，蓝图层）

- 中文营销与转化官网（桌面 + 移动 + 微信内置浏览器）
- **服务产品叙事**：精品咨询线、标准全流程线、垂直赛道矩阵
- **国家 / 学历 / 项目深度内容**（信息架构三维）
- **可筛选案例体系**、**可指定顾问体系**
- **服务生命周期可视化**、**费用与边界透明**
- **多通道即时转化**（微信/企微、电话、表单、预约回电）
- **活动 / 公开课**运营位
- **选校 / 背景评估工具**（可半自动：问卷 + 顾问解读）
- **最佳实践工作室 / Lab（能力域 R）**：Playbook + 工具矩阵，前期证明经验与方法论；自助探索 + 明示 DIY 天花板（详设见 Lab 说明）
- **社区飞轮（能力域 Q）**：登录可见的问答/经历/活动互动层；冷启动供给；合规治理；防爬与 SEO 隔离（详设见社区设计说明）
- 内容中心（指南 / 政策 / FAQ）与站内探索机制
- SEO / AEO / GEO 与多平台分发规范（增长层；**不含**社区 UGC 全文投喂）
- 运营后台：内容、案例、顾问、活动、线索、Lab 配置、社区审核、基础设置
- 埋点、隐私与广告合规、线索 SLA

### 1.4 范围外（Out of Scope，蓝图诚实声明）

下列能力**出现在竞品对照中，但不进入本项目建设承诺**（除非未来单独立项）：

| 不做 | 原因（对齐调研报告 §6.2） |
|---|---|
| ApplyBoard / Edvoy 级全球项目库与一键网申 | 无院校 API、合规与运维体量不匹配 |
| 前途级全国城市分站、200+ SKU 产品中心 | 初创不拼网点与 SKU 数量 |
| IELTS 官方身份、路径大学独家运营（IDP / Shorelight / INTO 模式） | 商业模式不同 |
| 学员端完整申请进度门户、文书协作工作台 | P2 路线图，非当前交付 |
| 多语言站群、海外贷款/住宿自营 | 非中国区首发优先级 |
| 无法核验的「成功率 X% / X 倍」主视觉 | 合规与信任红线 |
| 成瘾型黑产：恐吓倒计时、伪造热度、强制连环弹层 | 品牌与法律红线 |
| 马甲假用户灌水、公开可全文索引的 UGC 金矿 | 信任崩盘；与防爬/责任目标冲突 |
| 社区内包录交易、证件原件晒图、顾问承诺录取 | 合规红线（见社区公约） |
| 故意做残的伪工具、伪录取率、未出结果先锁死表单 | 伦理红线（Lab 必须真实有用 + 诚实门槛） |

### 1.5 假设与约束

| 假设 / 约束 | 说明 |
|---|---|
| 客群 | 大陆高中生、本科生、在职申请者及其家长；决策常为共同完成 |
| 团队 | 顾问人数有限；官网用「深」补「广」，禁止伪造顾问库规模 |
| 垂直首发 | 美本、英研、港新、低龄/K12、艺术留学（可扩展，模板可复用） |
| 技术 | CMS + 表单 + 可维护后台优先；半自动工具允许人工兜底 |
| 飞轮伦理 | 「不想走」来自清晰感与掌控感，禁止焦虑绑架 |
| 事实边界 | 竞品能力描述以调研报告与 `docs/竞品调研_*` 笔记为准，本文不新增未核验竞品事实 |

## 2. 调研结论如何进入需求

本章将 [竞品调研报告](./竞品调研报告_全球与中国头部留学平台.md) 的结论**翻译为需求约束**。未在报告中出现的竞品「能力」不得写入本 PRD 的对标列。

### 2.1 头部专业感的六层结构（必须同时在线）

调研报告 §0：专业感不是口号，而是以下六层可观察结构：

| 层 | 含义 | 对本 PRD |
|---|---|---|
| 1. 国家 × 学历 × 产品三维 IA | 前途「我想看/我想读」；启德国家+学历 | 站点地图必须三维可达，禁止单页介绍式导航 |
| 2. 可筛顾问 + 可对照案例 | 启德顾问库；无忧案例难点；Crimson 结果墙 | 案例与顾问为 P0 一级能力，非「关于我们」附录 |
| 3. 服务生命周期可视化 | 金吉列 STEP；新通服务全景；Shorelight Research→Career | 流程页 ≥5–7 步，含客户可见交付物 |
| 4. 多通道即时转化 | 国内 400+微信+表单；Leap WhatsApp → 换微信 | 企微/微信与表单并列，微信第一 |
| 5. 工具层降摩擦 | 前途 AI/费用/GPA；Shorelight quiz；新通选校 | P0 至少背景评估；P1 选校短名单/费用估算 |
| 6. 内容引擎持续获客 | 前途/启德资讯讲座；Studyportals 门户 | 国家/指南长尾 + 活动位；SEO/AEO 挂在其上 |

### 2.3 模式地图对本项目的取舍

| 模式 | 代表（报告事实） | 取 | 舍 |
|---|---|---|---|
| 国内连锁 | 前途、启德、金吉列、新通 | 信任深度、产品化、顾问/案例库形态、全流程文案 | 城市站体量、SKU 堆量、强销售弹层密度 |

### 2.4 中国区行为约束（进入全站）

依据 [中国区原则专章](./中国区留学用户行为与官网体验原则.md)：

- 决策单元含家长；关键转化页必须有「给家长看的一块」。  
- 高权重信息：层级锚、像我案例、费用总价感、时间表、避坑、顾问是谁。  
- 主通道是微信，不是邮件 nurturing。  
- 用户要「评估/规划」，不要电商式「下单」。  
- 详细 15 条落地见本文 §7。

## 3. 产品定位与差异化

### 3.1 一句话定位

面向中国大陆家庭的**垂直深耕型留学工作室官网**：用与头部同构的服务骨架（国家/项目、案例、顾问、流程费用、工具、活动、即时咨询）证明专业；用**可看见的顾问与可核对的执行**区别于连锁「销售先行」；用**微信优先与人民币费用表达**本地化于 Crimson 类精品；用 SEO/AEO/短视频把注意力送回真相源——增长加速转化，但不伪装成产品本身。

### 3.2 相对前途 / 金吉列 / 启德的差异化（四句话，必须用模块证明）

| # | 差异化主张 | 官网必须可见的证明模块 | 禁止的廉价证明 |
|---|---|---|---|
| 1 | **比连锁更深** | 垂直赛道方法论页；节点交付物清单；「谁写文书、家长如何同步」写清 | 「我们更便宜」「名额内部」 |
| 2 | **顾问可见** | 顾问库可浏览；支持指定顾问评估；代表案例可点开 | 只放 Logo 墙或「百名专家」无真人 |
| 3 | **执行透明** | 生命周期步骤 + 客户可见交付物 + 投诉/更换顾问机制入口 | 签约前不谈边界 |
| 4 | **垂直专家感** | 五条垂直深度页 + 该赛道案例/顾问标签强绑定 | 假装覆盖 30+ 国全品类 |

### 3.3 相对海外头部的本地化差异

| 对标 | 学 | 改 |
|---|---|---|
| Crimson | 结果墙、顾问叙事、免费咨询主 CTA | 微信支持为主；费用人民币区间/逻辑；家长字段 |
| IDP | 免费边界、生命周期 | 不做 IELTS 身份叙事；顾问用小而真 |
| ApplyBoard / Edvoy | 步骤与工具降摩擦 | 结果是「短名单+顾问解读」，不是账号网申 |
| Studyportals | 意图化内容 IA | 体量克制，先国家×赛道×意图长尾 |
| Leap / Yocket | 移动即时、产品分层 | WhatsApp→企微；慎用高成功率百分比 |

### 3.4 品牌与产品架构（一个域名，三层叙事）

```
主品牌官网
├── 精品咨询线（Crimson / 啄木鸟型叙事）
├── 标准全流程线（前途 / IDP 型节点交付）
└── 垂直赛道矩阵（美本 / 英研 / 港新 / 低龄 / 艺术 …）
        ↑ 共享：案例库、顾问库、流程费用、工具、活动、线索池
```

- **精品线**：冲刺顶尖（以工作室真实能力为上限）；模块可拆（策略/文书/背景/面试）；主 CTA「预约评估」。  
- **全流程线**：选校到签证行前；清单化；家长同步方式显性；主 CTA「获取方案与报价」或评估。  
- **垂直线**：每页独立意图、FAQ、表单来源、该赛道顾问与案例；是 SEO 与投放主着陆。

### 3.5 成功定义（能力视角，非仅「能留资」）

上线 90 日内，同时满足：

1. **骨架完整**：国家/赛道内容、可筛案例、可指定顾问、流程费用、微信通道、活动位（可先少场）、评估工具入口——用户不觉得这是电子名片。  
2. **转化闭环**：表单 / 电话 / 微信均可产生可跟进线索；工作时间首触 ≤15 分钟有页面承诺与值班机制。  
3. **差异可感知**：神秘访客调研中，≥70% 能说出「顾问可见 / 流程清楚 / 某条赛道很深」之一，而非「就是个介绍页」。  
4. **增长挂接**：sitemap / 答案块 / UTM 字典就绪；短视频回链可统计——但即使零投放，骨架页仍独立成立。

北极星指标仍为**月度 MQL**；辅以「骨架页完整度」与「飞轮健康度」（页深、回访、自然/AI 占比）。禁止以无法审计的录取成功率为官网主 KPI。

## 4. 完整能力蓝图（对标头部）

> **读表说明**  
> - **蓝图要求**：目标态专业表达（文档不收缩）。  
> - **P0/P1/P2**：该分期的实现深度。

### 4.3 「看起来专业」的最低完整集（P0 上线门槛）

4. 服务流程可视化（≥5 步）+ 费用/边界页  
5. 全站微信/企微 + 预约/短表 + 电话  
6. 背景评估入口（工具或等价强表单）  
7. 活动频道（即使场次少，IA 位必须在）  
8. 国家/赛道深度内容库存达标（见 §10）  
9. 页脚信任与合规页  
10. 后台线索可见且含来源  
11. **（强烈建议同期）最佳实践 Lab**：`/lab` 可见 + ≥6 Playbook + 工具矩阵（证明「有经验可自助摸索」）  

增长层（sitemap、答案块、UTM）随 P0 交付，但**不得用「只有博客飞轮」替代 1–7**。  
社区（能力域 Q）**不计入**上述 P0 专业骨架门禁；建议骨架+Lab 达标后再上，避免空城。若同期上线，必须满足社区设计说明 §11 门禁（登录墙、先审、精选库存、noindex）。

## 6. 核心模块需求

优先级定义：**P0** = 骨架上线必达；**P1** = 上线后 4–8 周增强；**P2** = 按签约量与运营带宽立项。  
每条含：对标模块、本期实现深度、规则要点、验收。

### 6.1 国家 / 项目深度内容

| 列 | 内容 |
|---|---|
| 对标模块 | 前途国家侧栏与知识库；Studyportals 学位门户；Crimson 大学档案；Leap 国家×意图长尾 |
| 蓝图 | 国家页覆盖条件框架、费用总账、时间表、签证要点、风险/避坑、相关垂直与案例；热门项目有解释页 |

**P0 深度**

- 垂直页内嵌：时间轴、硬条件框架、费用框架、方法 3 点、案例 2–3、FAQ 6–10（含 Schema）。  
- 独立国家页：至少覆盖工作室主推国家/地区骨架（与五垂直对齐，如美国/英国/香港/新加坡等——以实际服务清单为准）。  
- 指南库存：≥12 篇，意图覆盖条件/费用/时间/签证/避坑。

**P1 深度**

- 院校卡 30–80：名称、国家、层级锚（QS 等作筛选锚非承诺）、官方链接、相关指南、评估 CTA。  
- 热门项目解释页：课程类型、常见要求区间、费用年份、适合信号。

**规则**

- 数字标注年份与来源类型；排名不作唯一承诺。  
- 禁止整页抄袭院校版权长文；摘要 + 外链。  
- URL 意图化：`国家 + 学位/赛道 + 意图`。

**验收**

- 任意垂直页 2 次点击内可到对应国家或指南。  
- 费用相关页可见年份；抽检 3 页无过期未标注。

### 6.2 服务三线（精品 / 全流程 / 对比）

| 列 | 内容 |
|---|---|
| 对标模块 | 啄木鸟产品分层；启德高端命名；新通标签；Crimson 模块化；国内连锁一站式套餐叙事 |
| 蓝图 | 产品可理解、边界可核对、选择有对照表 |

**P0 — 精品线**

- 适合谁 / 不适合谁（明确拒绝信号）。  
- 模块：策略、文书、背景规划、面试、时间管理（按实际能力裁剪）。  
- 交付节奏；「不含保录」声明链至免责页。  
- 主 CTA：预约 45–60 分钟评估。

**P0 — 全流程线**

- 节点至少：背景评估 → 选校定校 → 材料与文书 → 递交与跟进 → 结果决策 → 签证 → 行前（可合并表达但逻辑 ≥6）。  
- 每节点：客户可见交付物 + 家长同步方式（企微周报/共享表等——写真实做法）。  
- 「不包含」列表：语言班学费、签证费、第三方考费等。

**P0 — 对比页**

- 表格：对象、周期、顾问密度、价格逻辑、适合信号。  
- 移动端可横滑或转定义列表。

**P1**

- 模块加购独立页（单文书、签证加项等）。  
- 产品级 FAQ 与案例绑定。

**验收**

- 三页均可到达预约；对比页无信息截断；全流程不含项可见。

### 6.3 案例体系（可筛选、可对照）

| 列 | 内容 |
|---|---|
| 对标模块 | 无忧可筛可搜 + 申请难点；前途案例分页+顾问署名；Crimson offer 墙 |
| 蓝图 | 用户能按「像我」过滤，并看懂难点与策略，而非奖杯墙 |

**P0 深度**

- 列表筛选：方向（垂直）、学历阶段、背景档（如 211/双非/国际课程等可配置标签）、入学年（可选）。  
- 卡片：脱敏背景摘要 + 结果层次 + 申请难点一句话。  
- 详情固定结构：背景 → 目标 → **申请难点** → 策略 → 执行 → 结果 → 顾问链接 → 免责（个案不代表概率）。  
- 数量 ≥8，每垂直 ≥1；后台可下架即时失效。

## 8. 转化与线索 SLA

### 8.1 决策漏斗（大陆习惯）

```
浏览内容 / 看案例 / 看顾问
  → 加微信 或 留手机「评估」
    → 1–3 次深聊（背景、选校、报价）
      → 签约（精品或全流程）
```

官网每一页只推进 1–2 步，并给出明确下一步。

### 8.2 多通道（P0 全开）

| 通道 | 场景 | 记录 |
|---|---|---|
| 短表单 | 内容/垂直/活动 | 后台 |
| 预约表单 | `/book`、工具结果 | 后台 + 通知 |
| 微信/企微 | 全站 | 二维码；P1 可回传「已添加」 |
| 电话 | 家长偏好 | `tel:` 点击事件 |
| 活动报名 | `/events` | `event_slug` |

### 8.3 渐进式表单

**第一层（投放页默认）必填尽量少**

| 字段 | 规则 |
|---|---|
| 称呼 | 2–20 字 |
| 手机 | 大陆 11 位 |
| 意向方向 | 美本/英研/港新/低龄/艺术/未定 |
| 隐私同意 | 必须勾选（记录政策版本） |

选填：微信同号、入学年份、学历阶段。  
原则：首次必填 ≤4（含同意）；垂直页可加「当前年级」提升 SQL。

**第二层（预约页/评估工具展开或顾问侧补）**

均分区间、语言成绩、预算区间、目标层次、是否已找其他机构、方便通话时段、`preferred_advisor`。

### 8.4 线索字段（后台）

线索 ID、时间、称呼、手机、微信、意向、入学年、来源 URL、落地 slug、UTM、表单变体、活动/工具来源、preferred_advisor、状态（新提交/已联系/MQL/SQL/无效/已签约/回收）、顾问备注、同意时间与政策版本。

### 8.5 分级与 SLA

| 级别 | 示例规则 |
|---|---|
| 无效 | 空号、明确无计划 |
| 冷 | 无年份、仅要资料 |
| MQL | 有方向 + 可联系 + 约 12–24 个月内入学 |
| 热 SQL | 有成绩/预算线索 + 明确产品意向 |

| SLA | 要求 |
|---|---|
| 工作时间首触 | ≤ **15 分钟**人工（电话或微信）；页面明示 |
| 非工作时间 | 自动回复「已收到，次日 XX 点前联系」+ 微信备选 |
| MQL→SQL 确认 | 48h 内顾问标注 |
| 超时 | P1 后台标红并升级通知 |

### 8.6 反垃圾与通知

- 节流、蜜罐、手机号段校验、同 IP/手机 10 分钟限 3 次。  
- P0：邮件通知顾问；P1：企微机器人按方向路由；重复手机合并。  
- 通知失败不得导致线索丢失。

### 8.7 转化文案基线

- 按钮：「预约免费评估」/「免费规划留学方案」类，不用「立即购买」。  
- 辅助：「工作日 15 分钟内联系，不向第三方出售信息」。  
- 成功页：强化加微；减少无关导航干扰。

## 9. 增长层：飞轮 / SEO / AEO / 短视频（挂在骨架上）

> **原则（任务书硬约束）**：增长飞轮是加速器，**不能替代** §4 服务骨架。无骨架的「纯内容站」或「纯短视频导流页」不符合本 PRD。

### 9.1 双层关系

```
[服务骨架] 国家/案例/顾问/流程费用/工具/活动/转化
      ↑ 内容与信任填充
[增长加速]
  ├── SEO/AEO：让骨架页被搜索与 AI 发现
  ├── 站内探索：让用户在骨架上变清晰
  └── 短视频/图文：把注意力送回骨架真相源
```

### 9.2 SEO / AEO（P0 基础，P1 运营闭环）

| 项 | P0 | P1 |
|---|---|---|
| 渲染与内链 | 关键正文爬虫可见；HTML 内链 | 死链监控 |
| sitemap/robots | 提交百度站长 + GSC | 抓取异常告警 |
| 结构化数据 | FAQ、Article、Breadcrumb、Organization | sameAs 与实体一致 |
| 答案块 | 指南/垂直强制；纯文本可复制 | AI 探测 20 问月度 |
| llms.txt | 品牌、服务、核心 URL | 随 IA 更新 |
| 问句标题 | 覆盖口语与 AI 问法 | 回流选题池 |

关键词簇优先长尾与问句（条件/费用/时间/避坑/赛道），而非只冲「留学中介」头词。

### 9.3 站内探索机制（原「黑洞飞轮」，伦理约束保留）

| 机制 | 分期 | 说明 |
|---|---|---|
| 答案块、进度、下一站、清晰小结、像我入口 | P0 | 嵌入指南/垂直模板 |
| 清单、匹配测验、继续上次、收藏路径 | P1 | 工具章 |
| 个性化、克制成就 | P2 | 可关 |

**允许 / 禁止** 同 v1.1 伦理表：正向微反馈 ✓；伪造热度、无依据倒计时、诱导分享才看结论 ✗。

### 9.4 多平台分发（小红书 / 抖音 / 视频号）

| 层级 | 职责 |
|---|---|
| 官网 SoT | 完整、可引用、可转化 |
| 小红书 | 图文种草、避坑、案例切片 → 回链 |
| 抖音/视频号 | 15–60s → 主页/聚合/企微 |
| 微信 | 成交闭环 |

流水线：选题 → 官网写/更新 SoT → 拆原子 → 适配发布（UTM）→ 数据回流。  
P0：UTM 字典 + `social_hooks` 字段。P1：短链 `/go/*`、运营手册。P2：原子库日历。

### 9.5 增长层验收（附骨，不单飞）

- 无 §4.3 骨架完整集，不得以「SEO 已做」宣称 P0 完成。  
- 有骨架时：AC 含 sitemap、答案块、UTM 识别、下一站点击事件。

### 10.2 指标体系

| 层级 | 指标 | 定义 | 90 天建议 |
|---|---|---|---|
| 骨架 | 骨架页完整度 | §4.3 清单勾选率 | 100% |
| 获客 | 自然搜索会话 | 百度/谷歌 organic | 建基线后提升 |
| 获客 | 内容获客 MQL 占比 | 指南/国家/垂直来源 | ≥40% |
| 获客 | 短视频回链会话 | UTM 社媒 | P1 考核 |
| 留存 | 页深中位数 | pages/session | ≥2.5 |
| 留存 | 内容页有效停留 | 有交互停留 | ≥90s |
| 转化 | 全站 CVR | 线索/会话 | 移动≥2.5% / 桌面≥3.5% |
| 转化 | 评估提交率 | 成功/到达评估或预约 | ≥25% |
| 质量 | MQL→SQL | 48h 确认 | ≥40% |
| 效率 | 首触时长 | 提交→人工 | 工作时间≤15min |
| 体验 | 移动 LCP | 核心模板 | ≤2.5s |
| 收录 | 索引覆盖 | 已发布可索引 URL | 30 日后≥70% |
| AEO | 可引用页占比 | 答案块+FAQ+日期+byline | 指南与垂直 100% |

禁止：无法审计录取成功率作主 KPI；恐吓倒计时转化率实验。

### 10.3 合规与广告法红线

- 不承诺录取；案例可脱敏、可下架；标注个案不代表概率。  
- 不用「成功率是平均 X 倍」「包录」「内部名额」等无法审计表述。  
- 个人信息：同意勾选、版本、可撤回/删除（P0 可人工）。  
- 服务对象年龄策略写清（对标头部常见 18+；低龄业务单独监护人流程）。  
- ICP、主体信息页脚预留并随备案更新。  
- 投诉/质量监督入口可见（对标新通双热线所传递的正面信号，实现形式可轻量）。

### 10.4 非功能需求（摘要）

- **移动优先**，微信内置浏览器为验收浏览器之一；点击域 ≥44px；二维码与 `tel:` 真机测。  
- **性能**：核心 LCP≤2.5s；图片压缩；第三方脚本异步。  
- **安全**：HTTPS；表单防护；线索最小权限；密钥不进仓库。  
- **无障碍基线**：键盘可完成预约；错误与 label 关联；信息不只靠 hover。  
- **浏览器**：近两版 Chrome/Safari + 微信内置；不支持 IE。

### 10.5 设计约束（体验，非空洞品牌词）

- 第一视口一个构图；品牌名英雄级信号。  
- 避免 Inter/Roboto/系统默认栈作品牌字体；背景有层次。  
- 英雄图默认全宽；默认不用卡片，卡片仅作案例/文章等交互容器。  
- 每区块一个目的；2–3 处有意图动效服务反馈。  
- 避开：紫白渐变套路、奶油衬线+陶土、报纸细线密栏、土促销红爆奖杯墙。

## 12. 非目标与红线

### 12.1 非目标（本周期不承诺）

- 成为 ApplyBoard 式全球网申平台  
- 成为前途式全国连锁官网体量  
- 以「最低价」或「限时抢位」为品牌主叙事  
- 用短视频矩阵替代官网服务骨架  
- 用无法核验的录取率广告作增长引擎  

### 12.2 红线（出现即评审否决）

1. 包录 / 内部名额 / 保证录取  
2. 伪造顾问人数、海外履历、案例  
3. 恐吓倒计时、伪造「正在咨询」热度  
4. 强制连环弹层阻断阅读  
5. 签约前隐瞒费用逻辑与不含项  
6. 出售线索给第三方  
7. 关键结论仅存在于图片/短视频、官网无 SoT  

### 12.3 文档治理

- 需求变更须更新本 v2 的能力表分期列，不得只改开发看板。  
- 与 [业务架构 v2](./留学服务官网_业务架构文档_v2.md) 冲突时，先对齐业务能力地图再改页面需求。  
- 竞品事实更新以调研报告修订版为准，同步影响「对标模块」列。
