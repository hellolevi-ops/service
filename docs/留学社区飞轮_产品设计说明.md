| 项 | 内容 |

## 0. 一句话定位

建设一个**大陆留学决策与在读互助社区**：用问答、经验、活动与圈层让用户「越逛越有同伴感、越清晰越愿意回来」；同时用**规则与产品机制**把平台责任压到可承受范围，并用**访问控制 + 反爬策略**降低被 AI / 同行批量抽取的风险。

**不是：** 对全网开放的 SEO 论坛、包录八卦站、无人值守贴吧。  
**是：** 「官方精选冷启动 → 受邀共建 → 登录后深互动」的三阶段飞轮。

---

## 1. 目标与非目标

### 1.1 目标

| # | 目标 | 可观测指标（建议） |
|---|---|---|
| G1 | 提升回访与会话深度（黑洞感） | 7 日回访率、社区页深、周活 |
| G2 | 覆盖「未留学 + 已留学」两端 | 角色标签占比；在读用户发帖占比 |
| G3 | 为评估/加微提供弱销售入口 | 社区 → 评估/企微 CVR（次级，不压社区体验） |
| G4 | 降低内容冷启动空窗 | 上线 30 天内「有价值帖」库存达标 |
| G5 | 可控风险与可辩护合规 | 违规处理时效、投诉量、下架闭环 |
| G6 | 提高爬取与滥用成本 | 未登录可见比例、异常流量拦截率 |

### 1.2 非目标（明确不做）

- 不做全站公开、可被搜索引擎完整索引的 UGC 金矿（与防爬目标冲突）。  
- 不做「保证录取 / 内部名额」讨论区（合规红线）。  
- 不做实时匿名裸聊而无审核（责任不可控）。  
- 不伪造「用户真实发帖」冒充 UGC（冷启动只用**明确标注**的官方/特邀内容）。  
- 不承诺「技术上绝对防爬」——只能**显著提高成本 + 合同禁止 + 监测打击**。

## 2. 用户与场景

### 2.1 角色

| 角色 | 动机 | 社区给他什么 |
|---|---|---|
| 意向学生 | 避坑、像我、同伴 | 问答、案例讨论、活动、清单打卡 |
| 家长 | 费用、安全、过程 | 家长专区（可选）、官方答疑 AMA |
| 申请中 | 节点焦虑、文书/选校对照 | 节点话题、截止日日历、互助答疑 |
| 在读留学生 | 表达、帮助学弟妹、资源 | 在读圈、城市生活、选课打工经验 |
| 校友/毕业 | 就业回流、声誉 | 职业分享（克制）、特邀 AMA |
| 顾问/官方 | 专业背书、纠错 | 「官方/顾问」标识发言；不主导灌水 |
| 运营/版主 | 秩序与冷启动 | 精选、置顶、活动、治理 |

### 2.2 关键场景

1. 搜到官网指南 → 登录看「同背景讨论」→ 收藏话题 → 周回访。  
2. 在读用户周末发「本周选课避坑」→ 意向用户追问 → 官方补「声明：个人经验」。  
3. 每月「拒信复盘会」线上活动 → 报名（轻表单）→ 回放仅登录可见。  
4. 同行/爬虫尝试批量抓取 → 撞登录墙 / 频控 / 无完整正文 → 告警。

## 3. 信息架构与内容类型

### 3.1 频道建议（可分期裁剪）

| 频道 | 内容形态 | 主要角色 | 风险等级 |
|---|---|---|---|
| 问一问 | 结构化问答（国家/赛道标签） | 意向+在读 | 中 |
| 经历馆 | 申请季复盘、在读日记（脱敏） | 申请中+在读 | 中高 |
| Offer/结果墙（社区版） | 自愿脱敏结果分享（非官方案例库） | 申请中 | 高 |
| 在读生活 | 城市、住宿、打工、心理 | 在读 | 中 |
| 家长会客厅 | 费用、监护、沟通（可选 P1） | 家长 | 中 |
| 活动广场 | AMA、直播、主题周、打卡挑战 | 全体 | 低–中 |
| 官方观察 | 政策解读、避坑清单（SoT 摘要链回官网） | 官方 | 低 |

社区 **Offer 墙** 与官网 **签约案例库** 必须分库：前者为用户自愿分享且强免责；后者为工作室交付案例且可核验授权。

### 3.2 内容形态（持续互动）

- 帖子 / 回复 / 追问  
- 投票 / 问卷轻互动（「你卡在哪一步」）  
- 打卡与清单（申请周进度，隐私默认仅自己可见，可选手动公开）  
- 线上活动：AMA、主题讨论会、拒信复盘、在读连线  
- 精选合集（运营编辑，每周一期）  

### 3.3 可见性分层（核心防爬设计）

```
L0 公开展示（可 SEO）：频道介绍、活动预告标题、精选摘要 1–2 句、登录引导
L1 登录可见：帖文全文、评论、活动回放、合集全文
L2 身份可见：在读认证区、家长区、敏感话题（可选）
L3 仅参与者：活动房间、私信（若做，P2 且强风控）
```

**原则：** 公网爬虫与未登录 AI 抓取最多拿到「目录 + 诱饵摘要」；价值密度在 L1+。

## 4. 责任与风险规避（产品 + 法务 + 运营）

> 下列为产品设计约束；最终条款须法务审定，本文不构成法律意见。

### 4.1 法律定位（建议表述方向）

| 点 | 设计要求 |
|---|---|
| 平台性质 | 用户生成内容交流空间；**非**留学中介承诺渠道、**非**专业法律/移民意见 |
| 与付费服务边界 | 社区发言 ≠ 工作室服务合同；付费评估/签约走官网正式通道 |
| 信息性质 | 同伴经验与公开信息讨论；可能过时/片面；须自行核实 |
| 年龄 | 默认 18+；低龄相关讨论须监护人规则（可与官网一致） |
| 个人信息 | 禁止晒证件、录取通知书含个人信息原图；默认脱敏模板 |

### 4.2 必上机制（上线门禁）

1. **《社区公约》+《用户协议》+《隐私政策》** 勾选同意后方可发帖。  
2. **免责声明** 固定在发帖页、帖底、活动页（个人经验、不代表平台与顾问意见）。  
3. **禁止清单** 显性：包录、代写作弊、虚假材料、买卖名额、人身攻击、广告拉人头、违法内容。  
4. **审核策略**：冷启动期 **先审后发**；规模起来后可「机审 + 抽检 + 举报」，高风险频道保持先审。  
5. **举报 / 下架 / 申诉** 闭环；处理 SLA（如 24–48h）。  
6. **顾问发言标识**：「官方/顾问」徽章；顾问不得在社区承诺录取结果。  
7. **案例分流**：用户晒结果 ≠ 官网签约案例；不得一键「冒充工作室战绩」。  
8. **日志与取证**：保留必要操作日志以应投诉（期限与最小必要原则）。

### 4.3 内容风险分级与动作

| 等级 | 例 | 动作 |
|---|---|---|
| 红 | 包录交易、证件原件、仇恨、明显违法 | 拒发/秒删 + 封禁评估 |
| 橙 | 未脱敏 offer、攻击竞品诽谤、医疗/心理危机 | 打码/限流/私信关怀指引（不做法疗） |
| 黄 | 过时政策、片面经验被当真理 | 官方评论纠偏 + 链 SoT |
| 绿 | 正常经验与提问 | 正常分发 |

### 4.4 平台「不做什么」以降低连带

- 不对社区帖做「成功率统计」营销主视觉。  
- 不把社区未核实内容写进广告素材。  
- 不设「匿名无成本」发帖（至少手机号/微信体系实名等级之一）。  
- 私信若上线：默认关闭陌生人私信或强限制（P2）。

## 5. 防爬取与防「同行挖矿」（务实策略）

### 5.1 策略分层

| 层 | 手段 | 作用 |
|---|---|---|
| 产品 | 登录墙、摘要截断、回放登录可见、禁止全文 RSS | 直接减少可抓语料 |
| 协议 | robots.txt Disallow 社区路径；页面 `noindex,nofollow`；ToS 禁止爬虫与训练 | 合规与起诉依据 |
| 技术 | 频控、IP/设备指纹、验证码、异常行为封禁、API 鉴权与分页签名 | 提高批量成本 |
| 呈现 | 关键段落图片化/字体扰乱（慎用，影响无障碍）；水印用户 ID | 提高清洗成本 |
| 运营 | 蜜罐帖监测竞品号；定期轮换接口 | 发现定向扒取 |
| AI 专项 | 不对社区全文开放 `llms.txt`；与官网 SoT 的 AEO **隔离** | 避免主动投喂模型 |

### 5.2 与 SEO/AEO 的边界（必须写清）

| 内容 | SEO/AEO | 社区 UGC |
|---|---|---|
| 官网指南 / 案例 / 顾问 | **鼓励**抓取与引用 | — |
| 社区帖全文 | **默认禁止**索引与摘要对外开放 | 登录后消费 |
| 活动预告标题 | 可索引（获客） | 详情/回放登录 |

社区飞轮的「黑洞」靠**登录用户回访**，不靠把 UGC 喂给全网搜索/AI。

### 5.3 不可承诺

任何「绝对防 AI 训练」在公开互联网上不成立。目标改为：  
**未登录不可得全文 + 批量行为可识别可打击 + 合同禁止 + 核心资产仍在 SoT 与服务交付。**

## 6. 冷启动：前期如何「有料」又不假

### 6.1 原则

1. **所有非真实用户帖必须标签**：`官方精选` / `特邀在读` / `顾问观察` / `活动纪要`。  
2. **禁止马甲装作路人** 灌水（暴露即信任崩盘）。  
3. 冷启动目标是「密度与质量」，不是「假热闹人数」。

### 6.2 内容获取清单（有效且可执行）

| 方式 | 做法 | 标注 | 建议阶段 |
|---|---|---|---|
| A. 官方精选库 | 把已有指南/避坑改写成「讨论帖」形态，文末链 SoT | 官方精选 | 上线前 |
| B. 特邀在读/校友 | 付费或服务抵扣，约稿 20–40 篇脱敏经历；签约授权 | 特邀在读 | 上线前–P1 |
| C. 顾问 AMA 纪要 | 每月 1 场，纪要沉淀为帖 | 顾问观察 | P0 |
| D. 活动驱动生产 | 「拒信复盘周」「选校清单打卡」用任务产出 UGC | 用户（审核后） | P0–P1 |
| E. 签约学员可选贡献 | 结案问卷邀请「是否愿意脱敏分享到社区」 | 用户+授权 | P1 |
| F. 微信群精华迁移 | 征得原作者同意后改写发布；不同意则只发主题不引原话 | 官方精选/授权转载 | 冷启动 |
| G. 公开信息二次编辑 | 政策/排名变化的「社区解读帖」+ 链官方来源 | 官方精选 | 持续 |
| H. 种子用户计划 | 邀请码制 50–100 人；贡献积分兑换评估优惠（非现金买量灌水） | 用户 | P0 |
| I. 跨站引流但不裸奔 | 小红书讨论引到「登录看完整帖」 | — | P1 |

### 6.3 冷启动 90 天节奏（建议）

| 周 | 重点 |
|---|---|
| W-2～0 | 准备 ≥30 条标注精选帖 + 公约/审核流 + 2 场活动预告 |
| W1–4 | 邀请码种子用户；每周 1 场 AMA；每日官方精选 1；先审后发 |
| W5–8 | 开放有限注册；打卡活动；在读认证试点 |
| W9–12 | 评估「真 UGC」占比；决定是否放松审核；强化防爬监测 |

### 6.4 「假繁荣」红线

- 不买僵尸粉、不刷赞、不显示虚假在线人数。  
- 可用「本周精选 12 篇」代替「10 万用户」话术。

## 7. 飞轮如何转（与官网骨架关系）

```
站外（小红书/抖音/微信群）
    → 活动预告 / 精选摘要（L0）
    → 注册登录
    → 社区深读与互动（L1）  ← 黑洞主场
    → 「仍不确定」→ 评估 / 企微（转化出口，弱打扰）
    → 签约交付 → 邀请脱敏分享回社区（供给）
    → 官方把高质讨论沉淀回 SoT 指南（注意：沉淀的是结构化结论，不是裸帖搬运）
```

**约束：**  
- 社区不能替代顾问/案例/费用页。  
- SoT 回写必须经编辑，去除可识别个人信息，并再走合规审核。

## 8. 分期（对标 × 本期深度）

| 能力 | 对标启发 | P0（可后置于官网骨架） | P1 | P2 |
|---|---|---|---|---|
| 登录墙 + L0/L1 | Yocket Feed 思路，但更封闭 | ● 注册登录、摘要、全文登录可见 | 身份认证（在读） | 家长区/私信强限制 |
| 问答+经历 | 知乎/小红书形态本地化 | ● 2 频道 + 标签 | 更多频道 | 个性化信息流 |
| 审核治理 | 平台标配 | ● 先审后发+公约+举报 | 机审辅助 | 信誉分 |
| 活动 | 启德直播/前途讲座 | ● AMA/主题周（可复用活动系统） | 系列活动+回放库 | 社群运营自动化 |
| 冷启动供给 | — | ● 官方精选+特邀稿库存 | 学员可选贡献 | UGC 自循环 |
| 防爬 | — | ● noindex+登录墙+频控+ToS | 指纹/蜜罐/监测看板 | 对抗升级 |
| 转化出口 | — | ◐ 帖内「预约评估」弱入口 | 按话题智能推荐顾问 | 社区积分权益 |

**建议排期：** 官网 **§4.3 专业骨架 P0 先上**；社区作为 **P1 主航道**（或官网 P0 后 4–8 周的「P0.5」），避免骨架未立先堆社区空城。若战略坚持社区与官网同期，则社区以「精选库+AMA」最小集上线，仍须登录墙与审核门禁。

## 9. 功能需求摘要（供 PRD 引用）

### 9.1 用户侧

- 注册/登录（手机号验证码优先；可绑定微信）  
- 浏览 L0；登录后 L1  
- 发帖/回复（同意公约）；标签（国家/赛道/阶段）  
- 点赞/收藏/关注话题（克制社交货币，避免成瘾设计）  
- 举报；个人主页（脱敏）  
- 活动报名与提醒（企微/短信择一）  

### 9.2 运营侧

- 内容审核队列；精选/置顶/下架  
- 官方/特邀内容类型标记（不可冒充普通用户）  
- 敏感词与广告拦截  
- 数据：发帖、审核时长、回访、异常爬取告警  

### 9.3 技术侧（要点）

- 社区路由默认 `noindex`；与官网 sitemap 隔离  
- API 需登录态；列表接口截断正文  
- Rate limit；风控名单  
- 附件扫描；图片 EXIF 剥离  
- 不向 `llms.txt` 暴露社区 URL

## 10. 指标与伦理

| 类型 | 指标 | 备注 |
|---|---|---|
| 健康 | WAU、人均帖互动、7 日回访 | 主看留存 |
| 供给 | 月新增「非官方」优质帖占比 | 冷启动后应上升 |
| 安全 | 违规率、处理时效、复投投诉 | 红线 |
| 防爬 | 未登录正文请求占比、4xx/封禁数 | 告警 |
| 转化 | 社区→评估（观察指标，不强制优化到伤体验） | 次级 |

伦理同 PRD：禁止恐吓倒计时、虚假热度、赌博式抽奖换咨询。

## 11. 验收清单（社区独立上线门禁）

- [ ] 公约/协议/免责/禁止清单可访问且发帖强制同意  
- [ ] L0/L1 可见性符合设计；抽样确认未登录无全文  
- [ ] robots/`noindex` 生效；sitemap 不含社区帖  
- [ ] 先审后发或等价风控在冷启动期开启  
- [ ] ≥30 条标注精选/特邀库存；无马甲假用户帖  
- [ ] 举报下架闭环可用  
- [ ] 频控与基础异常监测可用  
- [ ] 社区与官网签约案例库数据隔离  
- [ ] 转化入口存在但不遮挡阅读
