## 0. 结论先行

头部「专业感」**不是**来自单页介绍或口号，而是来自可观察的六层结构同时在线：

1. **国家 × 学历 × 产品** 三维信息架构  
2. **可筛选的顾问 + 可对照的案例**  
3. **服务生命周期可视化**（规划→背景→考试→申请→签证→行前→就业）  
4. **多通道即时转化**（400 / 微信 / 表单 / 预约回电）  
5. **工具层**（评估 / 选校 / 费用 / GPA / AI）降低决策摩擦  
6. **内容引擎**（资讯 / 白皮书 / 讲座 / SEO 长尾）持续获客  

本项目应对齐的是上述**能力蓝图的专业表达**；分期可克制体量，但文档与官网结构不能停留在「工作室电子名片 + 飞轮口号」层。

差异化建议（相对前途/金吉列）：**小而深、顾问可见、执行透明、垂直赛道专家感**——用模块证明，而非用「更便宜」证明。

## 3. 单平台摘要（完整模板见源笔记）

以下仅摘「对本项目决策最关键」的事实；细节以源笔记为准。

### 3.1 新东方前途出国

- **导航事实：** 「我想看」（顾问/方案/院校/讲座/案例/资讯/AI选校/知识库/问答/求职）×「我想读」（硕博本预科中学）双轴；国家侧栏全覆盖。  
- **产品事实：** `/Product/` 产品中心分页；常春藤工作室、少年赢、Super ALICE、尊享/启航等命名；CTA 统一「免费规划留学方案」。  
- **转化事实：** 意向国家+手机；「15 分钟回电」；官方小程序/公众号；城市选择弹层；服务声明 18+。  
- **工具事实：** AI 选校、费用、ROI、GPA、评估。  
- **借鉴：** 双轴 IA、方案产品化、工具矩阵、顾问卡字段。  
- **不照搬：** 41+ 页产品库体量、集团语培与全国城市站规模。

### 3.2 启德教育

- **事实：** 热线 400-1010-123（8–24 点）；产品库「共226」；顾问库「共682」可筛；高端命名（领樽/金枫叶/尊享/SO-HK）；白皮书搜索占位；留资含「授权三年」勾选；i启德小程序。  
- **借鉴：** 顾问/产品可筛库、高端命名体系、直播活动运营位。  
- **不照搬：** 75 分中心 / 境外直营数字、全品类培训捆绑。

### 3.3 金吉列留学

- **事实：** FAQ 自述 1999、49 分公司、2000+ 顾问、30+ 国家；流程含「危机处理」；顾问 `/chief` 可按国家筛；双微信+抖音；多层弹层留资；400-010-8000。  
- **借鉴：** 全流程 STEP 文案、顾问可指定、社媒矩阵。  
- **不照搬：** 「名校申请成功率99%以上」类表述（合规风险）、分公司体量。

### 3.4 新通教育

- **事实：** 留学/外语/求职/移民/保研集团线；「智能首席留学专家」Chat；产品标签星途/智领/双保险；案例查询；咨询与投诉双热线；服务全景含签证行前就业留后升级选购。  
- **借鉴：** 服务全景时间轴、投诉通道显性、AI 入口与案例检索。  
- **不照搬：** 国资规模叙事、全集团多品牌站群。

### 3.5 嘉华世达

- **事实：** 「中国留学服务中心官方所属」强背书；国际课程+雅思机考+签证代办+荟客厅；转化以 010-67084068 / 到访为主；几乎无在线留资漏斗；部分客户服务链 404。  
- **借鉴：** 官方资质如何呈现。  
- **不照搬：** 弱数字化漏斗、机构站信息架构。

### 3.6 啄木鸟教育

- **事实：** 美本无忧计划（4对1、TOP50）、朴思快捷、精英、常春藤分层；「了解细则及报价」；0 元试听；考培+申请一体；朴新教育集团旗下。  
- **借鉴：** 垂直精品产品命名与适合人群边界。  
- **不照搬：** 仅美本为主的窄定位（若本项目多国则需扩展）。

### 3.7 无忧留学

- **事实：** 公开「服务费¥5,999起」；顾问卡案例数（如 3993）+年限；案例可筛可搜约 191 页；评估表字段完整；高校项目组驻点；小红书/抖音入口。  
- **借鉴：** 价格透明、案例「申请难点」结构、顾问量化。  
- **不照搬：** 价格战话术与「限时抢位」促销感（与精品定位冲突时）。

### 3.8 IDP

- **事实：** 零升学服务费文案；课程搜索/FastLane/奖学金/成本计算机/IDP Live App；中国多城办公室列表；Enquire 字段多（目的地、入学时间、资金、面询方式）；社媒无微信。  
- **借鉴：** 生命周期导航、免费边界写清、工具+App 追踪。  
- **不照搬：** IELTS 官方身份、全球办事处体量、纯佣金对中国精品定价的直接套用。

### 3.9 ApplyBoard

- **事实：** 150,000+ programs、1,500+ institutions、宣称 ~95% application success；6 Steps（Register→Visa）；Student/Partner/Institution 三端；360 Solutions（贷款/付款/签证）。  
- **借鉴：** 步骤可视化、三端分流、增值打包叙事。  
- **不照搬：** 全库网申、95% 成功率营销口径。

### 3.10 Edvoy

- **事实：** AI 搜课+顾问；Express Offer；Funds/Stays；App；成都办公室与 +86 电话；页脚 UK 公司 moratorium 声明；Edvoy on ChatGPT。  
- **借鉴：** AI+顾问双轮、增值零服务费包装、AEO 实验。  
- **不照搬：** 企业监控状态风险信号、印度中东网络体量。

### 3.11 Studyportals

- **事实：** 「Education choice transparent, globally」；Bachelors/Masters/PhD 等门户矩阵；学生/院校双 CTA；院校案例（如 Portsmouth 增长文案）。  
- **借鉴：** 学位分层 SEO、双角色首页。  
- **不照搬：** 全球多域内容工厂体量。

### 3.12 Crimson Education

- **事实：** 中文站 `/zh`；「立即预约免费咨询」；藤校 offer 枚数墙；顾问 G5/藤校背景叙事；「获取中文微信支持」；低龄预备产品线。  
- **借鉴：** 结果证明墙、顾问透明、免费咨询主 CTA、微信入口。  
- **不照搬：** 1700+ 藤校量级与「7x」对比营销（合规与证明成本）。

### 3.13 Shorelight

- **事实：** 41,000+ students；Signature Schools 卡含排名/学费/国际生比例；school match quiz；Research→Career 服务链；对学生「no additional cost」；Career Premium 另合同。  
- **借鉴：** 匹配测验、院校决策信息密度、全链路图。  
- **不照搬：** 美路径项目独家合作模式。

### 3.14 INTO

- **事实：** 企业站偏大学合作（招聘/AI admissions/pathways）；Student site / Agent site 分流；香港办公室。  
- **借鉴：** 端分流清晰、路径项目解释。  
- **不照搬：** B2B 主站结构用于 C 端初创官网。

### 3.15 Leverage / Yocket / Leap（印度数字化参考）

- **共同事实：** Shortlist/Premium/Prep/Finance 分层；WhatsApp/电话即时；贷款与住宿数字条；社区（Yocket Admits & Rejects）；成功故事长文。  
- **对中国启示：** 移动即时通道、产品分层命名、社区「录取/拒信」透明度；须替换为微信生态与人民币费用表达，慎用高成功率百分比。

## 6. 对本项目的战略启示

### 6.1 必须对齐的专业骨架（蓝图）

官网能力地图至少包含：国家/项目深度内容、可筛选案例、可指定顾问、服务流程可视化、费用与边界透明、微信/企微即时咨询、活动/公开课、选校或评估工具（可半自动）。增长飞轮（SEO/AEO/短视频）挂在骨架之上，**不能替代骨架**。

### 6.2 明确不做的体量（分期诚实）

- ApplyBoard 级全球项目库与一键网申  
- 前途级全国城市分站与 200+ 产品 SKU  
- IELTS 官方/路径大学独家运营  
- 无法核验的「成功率 X 倍 / 99%」主视觉  

### 6.3 差异化四句话

1. **比连锁更深：** 垂直赛道方法论与执行透明（谁写文书、节点如何同步家长）。  
2. **比平台更暖：** 真人顾问可见，而非纯自助账号。  
3. **比 Crimson 更本地：** 微信优先、费用人民币表达、家长决策字段。  
4. **比无忧更稳：** 可公开价格逻辑与边界，但不靠「限时抢位」土促销。
