## 1. 阶段目标

下一阶段围绕一个核心结果展开：把已经上线的 P0 网站，从“能够展示和收集线索”提升为“品牌口径统一、内容可运营、线索可跟进、数据可复盘、上线可持续”的业务系统。

阶段退出时应实现：

- 品牌、主体、服务承诺和合同口径保持一致。
- 首页及核心转化页中的数字、资质、案例和退费表述均有证据或明确口径。
- Directus 成为核心内容的统一真相源，后台修改能够稳定反映到前台。
- 每条有效线索均可查询、分配、跟进和统计，通知链路具备可验证的送达能力。
- 关键流量、互动和转化事件进入正式分析平台。
- 正式域名、HTTPS、备份、监控和发布回滚流程可以用于持续运营。

## 2. 优先级定义

| 优先级 | 含义 | 处理时限建议 |
|---|---|---|
| P0 | 正式推广或大规模引流前必须完成 | 1 周内 |
| P1 | 建立稳定运营闭环 | 2–4 周内 |
| P2 | 提升转化效率与交付体验 | 1–2 个迭代内 |

负责人缩写建议：

- 业务负责人：品牌、定价、合同、服务边界与最终决策。
- 运营：内容、渠道、活动、数据复盘与案例授权。
- 顾问：线索响应、资格判断、咨询、报价和交付反馈。
- 技术：系统、数据、安全、发布和监控。
- 法务/合规：主体、广告表述、合同、隐私与授权审核。
