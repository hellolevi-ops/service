## 1. 文档信息

### 1.1 编写目的

本文档基于全球主流留学服务平台（ApplyBoard、Edvoy、IDP、Studyportals、Crimson Education、Shorelight、INTO）及国内连锁机构（新东方前途出国、启德、金吉列等）的产品与获客模式调研，为一家**留学服务初创工作室**定义官网的产品范围、信息架构、转化体系与分期交付标准。

官网不是「机构介绍页」，而是**黑洞式内容飞轮 + 获客信任系统**：被百度/谷歌与豆包等 AI 持续找到并推荐；用户进来后因「可感知进步、可探索、可对照自己」而不愿离开；短视频/图文平台把注意力送回官网；最终被低摩擦评估转化为可跟进线索。

### 1.2 产品目标

1. 承接 SEO / SEM / 社群 / 转介绍 / 短视频流量，转化为可跟进线索。
2. 用专业内容与真实结果证明工作室能力，降低家长决策成本。
3. 同时承载三条服务叙事：**精品高端咨询**、**标准全流程服务**、**垂直赛道落地页**。
4. 为顾问提供结构化线索（背景、意向国家、阶段、时间窗口），提高首咨效率。
5. 构建**站内黑洞飞轮**：浏览即反馈、路径可续、内容可刷但不空洞，形成「越逛越清晰、越清晰越想评估」的正循环。
6. 构建**站外收录飞轮**：对搜索引擎（百度、谷歌等）与生成式 AI（豆包、文心、通义、ChatGPT 等）长期可抓取、可引用、可被推荐服务。
7. 构建**多平台内容飞轮**：官网为真相源（Source of Truth），小红书 / 抖音 / 视频号等为分发层，统一回链、统一素材库、统一话题日历。

### 1.3 范围内（In Scope）

- 中文营销官网（桌面 + 移动）
- 服务介绍（精品 / 全流程 / 垂直）
- 案例、团队、流程与费用透明度
- 预约评估与多通道留资
- 内容中心（国家 / 专业 / 政策 / FAQ）+ 沉浸式内容消费机制（见第 13 章）
- 搜索引擎 SEO + AI/GEO 可摘录与可引用结构（见第 14 章）
- 多平台分发接口与运营规范（小红书 / 抖音等，见第 15 章）
- 运营后台：内容发布、案例管理、线索查看与导出、内容原子库（分期）
- 基础 SEO、转化埋点、隐私合规页、飞轮行为埋点

### 1.4 范围外（Out of Scope，一期明确不做）

- ApplyBoard / Edvoy 级全球项目库与一键网申
- 学员端申请进度门户、文书协作工作台
- 多顾问排班系统、完整 CRM（可用表格 / 企微先跑）
- 多语言站、城市分站、海外支付与贷款产品
- 语言培训 LMS、签证电子递交系统
- 虚假或无法核验的「录取率 / 排名第一」宣传模块
- 成瘾型黑产手法：虚假红点、恐吓倒计时、强制连点、赌博式抽奖换咨询
- 一期不做完整短视频中台 / 自动剪辑工厂（P1–P2 再上）

### 1.5 假设与约束

| 假设 / 约束 | 说明 |
|---|---|
| 客群 | 中国大陆高中生、本科生、在职申请者及其家长 |
| 主转化通道 | 微信（企微 / 个微二维码）、电话、表单留资 |
| 团队规模 | 初创：顾问少、内容可外包或顾问兼职产出 |
| 合规 | 遵守《个人信息保护法》；教育咨询广告不得虚假承诺录取 |
| 品牌 | 一个主品牌，三条产品线，不拆独立域名 |
| 垂直首发 | 美本、英研、港新、低龄/K12、艺术留学 |
| 技术约束 | MVP 优先可维护 CMS + 表单，不自研重型中台 |
| 飞轮伦理 | 「不想走」来自掌控感与清晰感，而非焦虑绑架或虚假紧迫感 |

### 1.6 术语

| 术语 | 定义 |
|---|---|
| 线索（Lead） | 留下有效联系方式的访客 |
| MQL | 营销合格线索：字段完整、意向明确、可联系 |
| SQL | 销售合格线索：顾问确认有真实申请窗口与付费能力 |
| 评估预约 | 免费初诊 / 背景评估，主 CTA |
| 精品线 | 顶尖名校策略、文书、背景规划，高客单 |
| 全流程线 | 选校—材料—申请—签证—行前 |
| 垂直落地页 | 按国家 / 阶段 / 赛道的高意图获客页 |
| GEO | 面向 AI 搜索 / 摘要 / 问答的可摘录、可引用内容优化 |
| 黑洞飞轮 | 用户进入后持续获得「小进展反馈」，停留与回访自我强化的产品循环 |
| 多巴胺回路（本产品定义） | 完成微任务、解锁下一站、看到「像我」匹配、收藏路径、分享清单时的正向强化；禁止恐吓式刺激 |
| 内容原子 | 可跨官网/小红书/抖音复用的最小素材单元（一问一答、一案例切片、一时间轴节点） |
| 真相源（SoT） | 官网上经审核的权威正文；站外内容必须可回链到 SoT |
| AEO | Answer Engine Optimization，面向答案引擎 / AI 助手的优化 |

## 2. 市场与竞品洞察

### 2.1 行业结构：六种官网模式

全球「最专业」的留学服务并不只有一种网站，而是六种商业模式叠在同一条学生旅程上。初创工作室应**对标能力、不复制体量**。

| 模式 | 代表 | 官网关键能力 | 对本项目启示 |
|---|---|---|---|
| 申请撮合平台 | ApplyBoard、Edvoy | 15 万+ 项目搜索、匹配、申请质量检查、奖学金/贷款增值；宣称高申请完整度 | 一期不做全库网申；做「轻量院校/项目导购 + 顾问承接」 |
| 全球咨询网络 | IDP | 顾问规模与可信度、IELTS 考点、签证与行前、App 搜课/追踪 | 强调顾问专业、节点透明、全流程陪伴 |
| 内容引流平台 | Studyportals、Shiksha、Hotcourses | 按国家/学位/专业比较、海量 SEO、向院校卖线索 | 内容与院校/专业页是长期免费流量主引擎 |
| 精品咨询 | Crimson Education | 录取结果证明、前招生官/名校导师、免费咨询、服务模块化（文书/标化/背景） | Hero 与案例聚焦方法论与结果；主 CTA 为预约评估 |
| 路径/招生伙伴 | Shorelight、INTO | 大学合作项目落地页、询盘表单、邮件/短信培育、转化率优化 | 落地页矩阵 + 多入口留资 + 培育 |
| 国内连锁中介 | 前途、启德、金吉列、新通 | 资质、分中心、案例库、一站式套餐、语培捆绑 | 信任模块必备；避免「销售先行、顾问后置」的不信任感 |

### 2.2 标杆产品拆解（对官网有用的部分）

**ApplyBoard**  
学生侧：注册建档 → AI 搜课 → 多项目申请 → 文书/材料清单 → 签证/金融增值。机构侧：向院校输送完整申请。  
可借鉴：分步引导、材料清单降低失误、用数字建立可信（项目数、院校数）。  
不可照搬：无院校 API 与合规网申能力时，承诺「一键申请」会反噬信任。

**Edvoy**  
AI 匹配（Genie）+ 顾问 + 多国课程比较 + 申请/材料/截止日期一体。  
可借鉴：用问卷降低选校焦虑；比较学费/录取条件。  
一期落地：5–8 题匹配问卷，结果是「顾问解读 + 短名单」，不是自动录取预测。

**IDP**  
「顾问在你身边」+ 免费面询 + 搜课比较 + 签证/行前。信任来自规模、IELTS 所有权、线下网点。  
可借鉴：全流程节点可视化；顾问人设真实（方向、年限、案例，禁止编造海外履历）。  
初创替代：用「小而深」的顾问介绍 + 可核验案例，而不是伪造网点数量。

**Studyportals**  
全球选课比较引擎，年访问量级以千万计，向大学按展示/点击/线索/入学收费。  
可借鉴：URL 与标题按「国家 + 学位 + 专业 + 意图」结构化；对比表；FAQ 可被搜索摘录。  
一期落地：先做「国家页 + 热门专业页 + 政策/费用页」，再扩轻量院校库。

**Crimson Education**  
不公开套餐总价，用录取成果、专家阵容、个性化路径驱动「预约咨询」。文书可单卖。  
可借鉴：结果叙事（背景 → 策略 → offer）、服务拆模块、免费咨询作为唯一主按钮。  
注意：大陆广告法与平台规则下，不得使用无法核验的「录取率是平均 X 倍」。

**Shorelight / INTO**  
大学路径项目 + 询盘表单 + 自动化培育 + 直招转化。Shorelight 公开案例显示表单、全站转化率与培育是增长杠杆。  
可借鉴：每个垂直页独立表单与广告落地一致性；线索培育（资料包、公开课、评估提醒）。

**国内连锁**  
决策链路：了解需求 → 比资质/案例 → 咨询细节 → 签约。痛点是销售与执行顾问分离、文书模板化、售后断档。  
官网反击点：展示「谁执行、怎么执行、节点如何同步家长」，费用与服务边界写清。

### 2.3 大陆用户决策链路（设计全站的主轴）

```
初步了解（国家/费用/条件）
    → 对比机构（案例是否像我、顾问是否懂这条赛道）
    → 验证可信（资质、流程、差评风险、是否包录取）
    → 低成本试探（免费评估、资料、公开课）
    → 深度咨询（背景、选校、时间表、报价）
    → 签约（精品或全流程）
```

官网每一页只推进其中一到两步，并给出明确下一步。

### 2.4 初创相对巨头的定位策略

| 巨头优势 | 工作室官网应对 |
|---|---|
| 项目库与网申规模 | 不拼库，拼「匹配解释权」与执行质量 |
| 广告与分店 | 垂直词 SEO + 案例长尾 + 转介绍页 |
| 语培捆绑 | 合作导流即可，不自建培训站 |
| 标准化套餐 | 三线清晰报价逻辑 + 可加购模块 |
| 销售话术 | 首屏讲方法与边界，不讲「保录」 |

## 3. 产品定位与成功指标

### 3.1 一句话定位

面向中国大陆家庭的留学工作室官网：**搜索与 AI 持续推你进来，站内飞轮让你越逛越清晰不愿走，短视频把好奇送回真相源，免费评估把清晰变成行动**——同时售卖精品名校辅导与全流程申请服务，用垂直落地页承接美本、英研、港新、低龄、艺术等细分需求。

### 3.1.1 双飞轮总览

```
站外飞轮（获客）          站内飞轮（留存→转化）
搜索/AI 推荐 ──┐
小红书/抖音 ───┼──► 官网真相源 ──► 探索/测验/路径进度
社群转介绍 ────┘         │              │
                         │              ▼
                         │         「像我」案例/下一篇
                         │              │
                         └──────► 评估留资 ──► 顾问成交
                                      │
                                      ▼
                         案例/口碑/UGC 原子 ──► 再分发到站外
```

### 3.2 品牌架构（默认方案）

**一个主品牌，三层产品叙事，同一域名。**

1. **精品线（Crimson 型）**  
   对象：冲刺顶尖院校（美本 Top / 英 G5 / 港前三等，以工作室真实能力为上限）。  
   卖点：策略、文书、背景规划、面试、时间管理。  
   转化：预约 45–60 分钟评估。

2. **标准全流程线（前途/IDP 型）**  
   对象：需要选校到签证行前的家庭。  
   卖点：清单化执行、节点同步、材料质检、签证与行前。  
   转化：预约评估或「获取方案与报价」。

3. **垂直线（落地页矩阵）**  
   首发五个：美本、英研、港新、低龄/K12、艺术留学。  
   每页独立意图、独立 FAQ、独立表单来源标记。

### 3.3 北极星指标（双核）

1. **月度 MQL 数量**：有效手机号或微信号 + 意向方向之一。  
2. **飞轮健康度（复合）**：周回访用户占比 × 会话页深中位数 × 自然/AI 来源会话占比。  
   - MVP 先分别观测三子指标，P1 合成看板分数（0–100）。

### 3.4 指标体系

| 层级 | 指标 | 定义 | MVP 建议目标（上线 90 天，可按投放调整） |
|---|---|---|---|
| 获客 | 自然搜索会话 | 百度/谷歌等自然流量 | 建立基线后环比提升 |
| 获客 | AI/引用可见会话 | 来自 AI 产品或带 `utm_medium=ai` / referrer 可识别的会话 | 建立监测基线 |
| 获客 | 内容获客占比 | 来自博客/国家/专业页的 MQL / 全部 MQL | ≥ 40% |
| 获客 | 短视频回链会话 | 小红书/抖音/视频号 UTM 会话 | P1 起考核；P0 埋好 UTM |
| 留存 | 会话页深中位数 | pages / session（排除跳出单页广告） | ≥ 2.5 |
| 留存 | 平均有效停留 | 有滚动/交互的停留时长 | ≥ 90s（内容页） |
| 留存 | 7 日回访率 | 周内 ≥2 次访问的访客占比 | ≥ 12%（有内容库存后） |
| 飞轮 | 下一篇点击率 | 相关推荐模块点击 / 曝光 | ≥ 18% |
| 飞轮 | 微任务完成率 | 测验/清单勾选完成 / 开始 | ≥ 35%（P1） |
| 转化 | 全站 CVR | 线索 / 会话 | 移动 ≥ 2.5%，桌面 ≥ 3.5% |
| 转化 | 评估预约率 | 成功提交 / 到达预约页 | ≥ 25% |
| 质量 | MQL→SQL | 顾问 48h 内确认可跟进 | ≥ 40% |
| 质量 | 首咨出席率 | 预约后实际接通/见面 | ≥ 60% |
| 效率 | 线索响应时长 | 提交到首次人工触达 | 工作时间 ≤ 15 分钟 |
| 体验 | 移动 LCP | 核心页最大内容绘制 | ≤ 2.5s（4G 模拟） |
| 收录 | 索引覆盖 | 百度/谷歌已索引有效 URL 占比 | 上线 30 日后 ≥ 70% 已发布页 |
| 收录 | AI 可引用页占比 | 含答案块+FAQ Schema+作者/日期的页面占比 | 指南与垂直页 100% |

禁止将无法审计的「录取成功率」作为官网主 KPI。录取结果仅用于案例模块，且须可下架、可脱敏。  
禁止用「恐吓倒计时转化率」优化产品——该指标出现即视为违规实验。

### 3.5 成功定义（MVP）

同时满足：

1. 五个垂直页 + 首页 + 预约页可被索引，核心模板无阻断性 bug。
2. 表单、电话、微信三条通道均可产生线索并在后台可见。
3. 顾问能在后台看到来源页、UTM、意向字段。
4. 隐私政策与同意勾选生效，未同意不可提交。
5. 指南/垂直页具备「答案前置 + FAQ Schema + 相关下一站」飞轮最小闭环。
6. `robots.txt` / `sitemap.xml` 对百度与谷歌友好；关键页不被 `noindex` 误伤。

## 4. 用户与场景

### 4.1 角色

| 角色 | 目标 | 焦虑 | 官网要给的 |
|---|---|---|---|
| 学生 | 选对项目、材料不踩坑、时间来得及 | 排名焦虑、同质化文书、信息不对称 | 路径图、材料清单、像我的案例 |
| 家长 | 安全、性价比、过程可控 | 被销售话术、隐性收费、换顾问 | 流程、边界、谁负责、如何同步 |
| 顾问 | 高意向、字段全、少无效聊 | 空号、无预算、无时间窗口 | 分级线索、来源、问卷摘要 |
| 运营 | 更新案例/文章、看投放效果 | 发文难、线索丢 | CMS + 线索表 + 埋点 |

### 4.2 关键场景

**S1 搜索进入（SEO）**  
用户搜「英研 计算机 申请条件 2026」→ 专业/政策页 → 读完仍不确定 → 页内「免费评估是否匹配」→ 留资。

**S2 广告进入（SEM）**  
广告「港硕申请时间表」→ 港新落地页（与广告文案一致）→ 短表单（姓名、手机、本科背景、意向专业）。

**S3 社群/小红书进入**  
种草案例 → 案例详情（背景分档、策略、结果、免责）→ 预约评估。

**S4 家长比价**  
打开费用与流程页 → 看服务包含/不包含 → 微信咨询或预约。

**S5 高净值冲刺**  
精品线页 → 方法论与顾问履历 → 长预约（可选时间）→ 评估。

**S6 顾问跟进**  
线索进库 → 企微/电话 → 补全 GPA/语言/预算 → SQL 或回收。

**S7 黑洞浏览（站内飞轮）**  
搜到「双非英研均分」→ 指南答案块建立安全感 → 勾选「我的清单」一项打勾有反馈 → 相关推荐进案例「像我」→ 再进时间轴 → 清晰感累积后点评估（而非一进来就被表单打断）。

**S8 AI 问答进入**  
用户在豆包问「香港授课型硕士一年花多少」→ AI 引用本站带年份的费用页 → 点进官网 → 同页 FAQ + 评估 CTA。

**S9 短视频进入**  
抖音/小红书看 30 秒案例切片 → 评论区或主页链到官网案例详情（SoT）→ 站内继续飞轮或留资；UTM 标记平台。

### 4.3 主路径（必须在设计中可见）

```
流量（搜索 / AI / 短视频 / 社群）
  → 对应意图页（真相源）
  → 飞轮：答案块 → 微进展 → 下一站内容 → 「像我」案例
  → 信任模块（顾问 / 流程）
  → 主 CTA（预约评估）或次 CTA（微信 / 电话 / 资料包）
  → 线索池 → 人工触达 → 签约
  → 新案例/口碑原子 → 再分发站外
```

## 6. 转化漏斗与留资体系

### 6.1 漏斗


### 6.2 多通道（P0 全开）

| 通道 | 场景 | 记录方式 |
|---|---|---|
| 短表单 | 内容页、垂直页侧栏/文末 | CRM/后台 |
| 预约表单 | /book | 后台 + 邮件/企微通知 |

| 字段 | 规则 |
|---|---|
| 称呼 | 2–20 字 |
| 手机 | 大陆 11 位 |
| 意向方向 | 美本 / 英研 / 港新 / 低龄 / 艺术 / 未定 |

选填：微信同号勾选、意向入学年份、目前学历。

**第二层（预约页可展开或评估后顾问补）**

GPA/均分区间、语言成绩有无、预算区间、目标院校层次、是否已找其他机构、方便通话时段。

原则：首次不超过 4 个必填（含同意）。垂直页可多 1 个「当前学历/年级」以提升 SQL。

### 6.4 线索字段（后台）

- 线索 ID、创建时间
- 称呼、手机、微信号（若有）
- 意向方向、入学年份
- 来源 URL、落地页 slug、UTM（source/medium/campaign/content）
- 表单变体（短表 / 预约）
- 状态：新提交 / 已联系 / MQL / SQL / 无效 / 已签约 / 回收
- 顾问备注
- 同意时间与政策版本号

### 6.5 分级规则（P0 人工，P1 半自动）

| 级别 | 规则示例 |
|---|---|
| 无效 | 空号、营销号、明确无留学计划 |
| 冷 | 无年份、意向未定、仅要资料 |
| MQL | 有方向 + 可联系 + 12–24 个月内入学 |
| 热 SQL | 有成绩/预算线索 + 明确冲刺或全流程需求 |

工作时间 15 分钟内首触；非工作时间自动回复「已收到，次日 XX 点前联系」，并给微信备选。

### 6.6 CRM / 企微对接

- **P0**：后台列表 + CSV 导出 + 提交时发邮件到顾问邮箱；手机号在后台可复制。

- 前端节流 + 服务端校验手机号段
- 蜜罐字段
- 同一 IP / 手机 10 分钟内限 3 次
- 不在前端暴露内部通知地址

- 一篇内容只回答一个意图（条件 / 费用 / 时间轴 / 对比 / 避坑）。
- 答案前置：前 120 字给结论，再展开。
- 所有数字标注年份与来源类型（官网 / 政策 / 经验区间）。
- 结尾必有下一步（评估 / 案例 / 相关指南）——构成站内黑洞的「下一抽」。
- 禁止抄袭院校版权长文；摘要 + 外链官网。
- **一份真相源，多端分发**：官网正文为准；小红书/抖音只做切片，冲突时以官网修订为准。

### 8.2 关键词簇（首发）

| 簇 | 示例意图 | 着陆页 |
|---|---|---|
| 品牌 | 工作室名 + 留学 | 首页 |
| 赛道 | 美本申请、英研申请、香港硕士、新加坡私立、国际学校择校、艺术留学作品集 | 垂直页 |
| 条件 | 雅思均分、跨专业、双非英研、美本转学 | 指南 |
| 费用 | 英国硕士一年花费 2026、香港硕士学费 | 指南 |
| 时间 | UCAS 截止、港校轮次、美本早申 | 指南+垂直 |
| 签证 | 英学生签证材料、F-1 面签 | 指南 |
| 机构词 | 留学中介怎么选、文书包办风险 | 关于+对比+免责 |
| AI 问答句 | 「双非均分 80 能申港硕吗」「英研一年总花费」 | 指南答案块 |

长尾优先于「留学中介」头部词；**问句式标题**优先覆盖 AI 与人们的口语检索。

### 8.3 GEO / AEO（搜索摘要 + AI 助手可摘录）

面向百度/谷歌摘要，以及豆包、文心、通义、ChatGPT、Perplexity 等：

- 问句小标题（H2/H3）与口语 FAQ
- 对比表、步骤列表、定义列表（机器友好）
- FAQ / Article / Breadcrumb JSON-LD
- 作者/顾问 byline + 可见更新日期
- 答案块纯文本可读，**禁止关键结论只做在图片或短视频里**
- 引用官方来源时给出可访问外链，提升被 AI 采信概率
- 站点级 `llms.txt`：用短句说明「我们是谁、服务什么、核心页面 URL」
- 可选：对核心服务页提供简洁英文 slug 与中文并存，降低国际模型抓取歧义（不强制双语全文）

### 8.4 上线内容最低库存（MVP 验收）

| 类型 | 数量 |
|---|---|
| 垂直页 | 5（完整，含答案块+FAQ Schema） |
| 服务页 | 3 + 1 对比 |
| 案例 | ≥ 8（每垂直至少 1） |
| 顾问 | ≥ 2 |
| 指南 | ≥ 12（每垂直至少 2 篇时间或条件；全部含答案块） |
| 合规 | 隐私、条款、免责 |
| AI 入口 | `llms.txt` + sitemap |

### 8.5 更新节奏（运营）

- 政策/截止类：相关官方更新后 5 个工作日内修订或加「待核实」条
- 案例：每月至少 1 则（有则发，无则不编造）
- 指南：每周 1 篇可持续，或按投放需求突击
- **飞轮燃料**：每周至少产出 5 个内容原子（可用于小红书/抖音切片）
- **AI 保鲜**：被引用的高流量页每季度复核数字与日期

### 8.6 内链（黑洞拓扑）

指南 → 对应垂直页 → 案例 → 下一篇指南 → 预约。  
每页出站内链 ≥ 2 条「下一站」，禁止孤岛文章。  
相关推荐算法 P0 用标签规则；P1 可加「同方向 + 同阶段」协同。

## 9. 非功能需求

### 9.1 移动优先

- 设计与验收以 390 宽为第一视口，再适配桌面。
- 底栏不遮挡表单提交按钮（预约页可收起底栏）。
- 点击区域 ≥ 44px。

### 9.2 性能

- 核心模板 LCP ≤ 2.5s（生产环境、国内访问路径）。
- 图片 WebP/AVIF 或压缩 JPEG；懒加载非首屏。
- 第三方脚本（统计、客服）异步，失败不影响提交。

### 9.3 可用性 / 无障碍基线

- 键盘可完成预约表单
- 表单错误与字段 label 关联
- 颜色对比达到可读（正文非浅灰小字）
- 不把信息只放在 hover

### 9.4 安全

- HTTPS
- 表单 CSRF / 同源策略按技术栈落实
- 后台账号 MFA 或强密码 + 登录审计（P1）
- 线索数据最小权限；导出下载审计（P1）
- 不在仓库提交密钥、短信密钥

### 9.5 隐私与合规

- 收集最小化
- 提交前明示同意，记录时间戳与政策版本
- 用户可通过邮件/微信申请删除线索（流程写进隐私政策，P0 可人工处理）
- 广告与案例遵守不得虚假宣传；不写「包录」「内部名额」除非有可证事实
- ICP 等按实际托管地办理（需求：页脚预留备案号位置）

### 9.6 可靠性

- 表单提交成功以服务端为准；失败可重试且不重复计费类操作（无支付）
- 通知邮件失败时线索仍入库
- 监控：提交接口 5xx 告警（P1）

### 9.7 浏览器

- 最近两个版本的 Chrome / Safari / 微信内置浏览器
- 不支持 IE

## 13. 黑洞飞轮与沉浸体验需求

### 13.1 目标体验（产品语言）

用户来了「不想走」，不是因为焦虑被锁死，而是因为：

1. **立刻有收获**（答案块 / 一句话判断）——短期多巴胺  
2. **感到自己在变清楚**（清单打勾、路径进度）——掌控感 / 类内啡肽  
3. **总有合理的下一站**（相关内容、像我的案例）——探索欲  
4. **离开后想回来**（收藏路径、继续上次）——回访钩子  
5. **清楚时自然转化**（评估）——飞轮出口，而非打断入口  

### 13.2 伦理红线（强制）

| 允许 | 禁止 |
|---|---|
| 完成微任务的正向反馈（轻动效、文案祝贺） | 虚假红点、伪造「三人同时咨询」 |
| 清晰的申请时间轴与截止提醒（真实日期） | 无依据的「今天截止」「名额仅剩」 |
| 个性化推荐基于用户自选标签 | 暗中追踪敏感信息做歧视性定价 |
| 无限相关阅读（可跳过、可关） | 无法关闭的全屏拦截表单刷屏 |
| 分享清单/路径 | 诱导分享才能看结论 |

### 13.3 飞轮机制分层

| 机制 | 用户感受 | 优先级 | 说明 |
|---|---|---|---|
| 答案块 | 「啊，原来是这样」 | P0 | 每篇指南/垂直页固定组件 |
| 阅读进度条 | 「快看完了」 | P0 | 细、不抢主视觉 |
| 下一站推荐 | 「还想再看一条」 | P0 | 规则标签；展示标题+一句话理由 |
| 文末清晰小结 | 「我比刚才懂了」 | P0 | 「你现在可以确认的 3 件事」 |
| 「像我」案例入口 | 「有人和我一样」 | P0 | 按方向/背景档粗匹配 |
| 互动清单 | 「我推进了一步」 | P1 | 如材料清单勾选，本地存储 |
| 60 秒匹配测验 | 「得到一个标签结果」 | P1 | 结果导向垂直页，禁伪录取率 |
| 继续上次 | 「断点续看」 | P1 | localStorage / 登录后云端（云端 P2） |
| 收藏路径 | 「我的留学地图」 | P1 | 收藏文章/案例序列 |
| 轻成就 | 「连续搞清 3 个问题」 | P2 | 徽章克制，可关闭 |
| 个性化首页模块 | 「为你准备的今日 3 读」 | P2 | 基于自选意向 |

### 13.4 信息架构增补（飞轮相关）

```
/guides/{slug}          含答案块、进度、下一站、小结
/tools/checklist        P1 材料/时间清单工具
/tools/match            P1 匹配测验
/me/continue            P1 继续上次（也可做首页模块）
```

导航不增加噪音：工具入口放在内容中心与文内 CTA，不挤第一屏品牌区。

### 13.5 动效与反馈（体验）

- 勾选清单：短促确认（≤300ms），可减弱动效（系统「减少动态」时关闭）  
- 下一站切换：内容区过渡，不做整页炫光  
- 测验结果：揭示感 + 立即给出「建议阅读」而非销售话术墙  
- 全站至少保留 2–3 处有意图动效（与附录 C 一致），服务飞轮反馈而非装饰  

### 13.6 与转化的关系（重要）

- 首屏与内容前半段**优先给价值**，表单侧栏/文末出现；禁止一进来全屏强制留资（退出意图时可温和提示一次）。  
- 当用户完成 ≥2 个下一站或完成测验后，**提高评估 CTA 权重**（文案从「了解服务」变为「用你的背景做 15 分钟诊断」）。  
- 家长路径可缩短飞轮、更快到费用/流程页（用「我是家长」切换，P1）。

### 13.7 功能需求条目

**US-FW-01（P0）** 相关推荐组件：输入当前页标签，输出 2–4 条同站链接，含推荐理由（如「下一步：看时间轴」）。  
**US-FW-02（P0）** 答案块组件：独立 class/锚点 `#answer`，纯文本。  
**US-FW-03（P0）** 阅读进度（文章模板）。  
**US-FW-04（P1）** 清单工具：勾选状态本地持久化；导出/截图分享可选。  
**US-FW-05（P1）** 匹配测验 5–8 题，结果页预填评估表单方向字段。  
**US-FW-06（P1）** 「继续上次」：记录 last_content_url。  
**US-FW-07（P2）** 登录态同步收藏与进度（可与学员门户合并立项）。

## 14. 搜索引擎与 AI 持续收录 / 推荐体系

### 14.1 目标

让百度、谷歌等搜索引擎，以及豆包等 AI，在用户询问留学相关问题时，**稳定发现、信任、引用并导向本站服务页**，形成「内容更新 → 收录/引用 → 流量 → 更多内容预算」的站外飞轮。

### 14.2 技术可抓取性（P0）

| 项 | 要求 |
|---|---|
| 渲染 | 关键正文对爬虫可见（SSR/SSG 优先；若 CSR 须预渲染） |
| 性能 | 慢页会被降权；核心模板达第 9 章指标 |
| 链接 | HTML `<a href>` 内链，不靠纯 JS 跳转关键节点 |
| 地图 | `sitemap.xml` 含全部可索引 URL + lastmod |
| 机器人 | `robots.txt` 明确允许；后台/感谢页可 noindex |
| 规范化 | canonical 防重复；HTTP→HTTPS |
| 结构化数据 | FAQ、Article、Organization、Breadcrumb |
| AI 说明 | `/llms.txt` 简述品牌、服务、核心 URL、联系方式页 |

### 14.3 百度与谷歌运营（P0–P1）

- P0：注册百度站长平台、Google Search Console；提交 sitemap；修复「已发现未索引」。  
- P1：核心词排名周报；抓取异常告警；死链监控。  
- 内容：优先覆盖百度系用户口语词与地域词；谷歌侧保证技术信号干净（很多留学家长双引擎）。

### 14.4 AI / 答案引擎优化（AEO）

**内容层**  
- 每个核心问题一页或一节，标题即问题。  
- 答案块 40–80 字结论 + 分点展开 + 「因专业/年份而异」边界。  
- 费用/录取相关必须带年份，过期则降级展示。  

**信任层**  
- 真实顾问 byline、案例授权、外链官方政策。  
- 关于页写清主体信息，便于模型建立实体。  

**监测层（P1）**  
- 人工月度：在豆包/文心/通义等用 20 条标准问句探测是否提及/链接本站。  
- 记录「被引用 / 未被引用 / 被错误引用」并回流修订 SoT。  
- 为 AI 流量预留 UTM 或落地参数规范（能识别则记，不能则记 referrer）。

### 14.5 实体与知识图谱信号（P1）

- `Organization` Schema：名称、logo、sameAs（小红书/抖音/官网一致）。  
- 统一 NAP（名称-地址-电话）全网一致。  
- 重要服务页短摘要可被复述，避免模型幻觉乱编套餐。

### 14.6 功能需求条目

**US-AEO-01（P0）** `llms.txt` + Organization Schema。  
**US-AEO-02（P0）** 指南模板强制答案块字段，未填不可发布。  
**US-AEO-03（P1）** 后台「AI 探测问句」清单与上次结果备注。  
**US-AEO-04（P1）** 过期内容仪表盘（超过 N 天未审的政策页）。

## 15. 多平台内容飞轮（小红书 / 抖音 / 视频号等）

### 15.1 角色分工

| 层级 | 平台 | 职责 |
|---|---|---|
| 真相源 | 官网 | 完整、可引用、可转化、可合规存档 |
| 种草分发 | 小红书 | 图文笔记、案例切片、避坑、词条科普 → 回链官网或微信 |
| 注意力分发 | 抖音 / 视频号 | 15–60s 口播/字幕条 → 主页链或聚合页 |
| 成交闭环 | 微信 / 电话 / 表单 | SQL 与签约 |

原则：**站外制造情绪与好奇，站内交付清晰与转化**。不在评论区做无法核验的录取承诺。

### 15.2 内容原子流水线

```
选题（搜索词 / AI 高频问 / 咨询FAQ）
  → 官网写 SoT 长文或更新垂直页
  → 拆原子：金句、对比表、案例切片、清单、口播稿
  → 适配小红书图文 / 抖音脚本
  → 发布时带 UTM 或品牌检索词
  → 数据回流选题池
```

### 15.3 回链策略

| 平台限制 | 策略 |
|---|---|
| 外链受限 | 主页放官网；评论区「官网搜品牌名+关键词」；置顶笔记放路径 |
| 可挂链 | 使用 `utm_source` / `utm_campaign` 到对应 SoT |
| 微信生态 | 短视频 → 企微 → 自动回复官网文章链接 |

P0：在 PRD/运营手册中固定 UTM 字典。  
P1：官网提供 `/go/xhs`、`/go/dy` 短链跳转便于换链统计。  
P2：素材库后台（原子、封面、脚本状态、发布记录）。

### 15.4 账号与合规

- 账号主体与官网品牌一致；简介含「留学规划 / 申请辅导」边界，不写包录。  
- 案例二次分发必须再次确认授权范围（是否可出镜、是否可提校名）。  
- 广告投放与自然流量素材隔离管理，落地页与广告三要素一致。

### 15.5 运营节奏（建议，非开发阻塞）

| 频率 | 动作 |
|---|---|---|
| 每周 | ≥3 条小红书或 ≥3 条短视频（可从原子复用） |
| 每周 | 1 篇官网 SoT 或重大更新 |
| 每月 | 1 次「平台热门问句 → 官网 FAQ」对账 |
| 每季 | 淘汰过期切片，避免站外旧数字与 SoT 冲突 |

### 15.6 功能需求条目

**US-SOC-01（P0）** UTM 字典文档；线索与分析识别 `xiaohongshu` / `douyin` / `shipinhao`。  
**US-SOC-02（P0）** 案例/指南后台字段：`social_hooks`（建议标题/封面文案，供运营复制）。  
**US-SOC-03（P1）** 短链跳转与点击统计。  
**US-SOC-04（P1）** 运营手册页（可放 Notion，链到后台）：原子拆解模板、违禁词表。  
**US-SOC-05（P2）** 原子库与发布日历。

### 15.7 成功标准（增长阶段）

- 短视频/图文贡献的会话占比可监测，并出现首批 MQL。  
- 站外热门话题能在 7 日内沉淀为官网 SoT，避免「只有流量没有资产」。  
- AI 探测问句中，至少有一批核心费用/条件问题稳定指向本站表述。

## 附录 B. 表单文案原则

- 按钮：「预约免费评估」而非「立即提交」
- 辅助：「顾问 工作日 15 分钟内联系，不向第三方出售信息」
- 成功：「已收到。请添加微信备份沟通。」

## 附录 C. 设计约束（与前端实现）

- 第一视口一个构图，不像后台仪表盘
- 品牌名是第一屏主信号
- 字体避免 Inter / Roboto / 系统默认栈作为品牌字体
- 背景需有层次（摄影、纸感、克制纹理），禁止纯色一块到底作为唯一氛围
- 落地/促销页英雄图默认全宽，不把主视觉放进圆角卡片
- 默认不用卡片；卡片仅用于可点选的案例/文章交互容器
- 每区块一个目的、一个标题
- 至少 2–3 处有意图的动效（如第一屏入场、CTA 状态、案例筛选过渡、清单勾选反馈），不作装饰性循环闪烁
- 飞轮反馈动效服务于「完成感」，禁止闪烁促销、假热度跳动
- 避开：紫白渐变套路、奶油衬线+陶土、报纸细线密栏
