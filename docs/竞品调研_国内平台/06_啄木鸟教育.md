## 2.7 可借鉴 5 / 不可照搬 3

### 可借鉴
1. **产品命名清晰分层**（无忧/朴思/精英/常春藤）对应不同客群痛点  
2. **适合人群清单**写在产品页降低错配  
3. **家长侧服务**（家长帮、留美课堂）提升决策参与  
4. **服务可视化/节点把关**话术增强过程信任  
5. **考培×申请一体化**与「0元试听」获客

### 不可照搬
1. 「相同的分数，更好的结果」类结果承诺表述  
2. 桥梁/低分赴美路径的合规与预期管理成本  
3. 站点技术陈旧（浏览器过低提示）损害专业感，不宜作为体验标杆
