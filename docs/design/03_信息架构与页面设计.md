## 3. 导航设计

### 3.1 桌面一级导航

| 顺序 | 项 | 子级 | 备注 |
|---|---|---|---|
| 1 | 服务 | 精品 / 全流程 / 如何选择 / 流程与费用 | 产品骨架 |
| 2 | 留学方向 | 五垂直 | 高意图 |
| 3 | 国家与指南 | 国家入口 + 内容中心 | SEO |
| 4 | 案例 | — | 信任 |
| 5 | 顾问 | — | 信任 |
| 6 | 工具与实践 | Lab 首页 + 评估快捷 | 经验门面 |
| 7 | 活动 | — | 运营位 |
| 8 | 关于 | 工作室 / 信任 / 联系 | 合规 |
| — | **免费评估**（主按钮） | → `/book` | 原则 #3 |
| — | 微信 / 电话（工具区） | 弹层码 / `tel:` | 原则 #2 |

社区 P1 上线后可置于「工具与实践」旁或页脚，**不挤占**案例/顾问一级位。

### 3.2 移动导航

```
┌─────────────────────────────┐
│ Logo          评估  ☰       │
├─────────────────────────────┤
│ … 页面内容 …                │
├─────────────────────────────┤
│  评估  │  微信  │  电话     │  ← StickyMobileDock
└─────────────────────────────┘
```

- 汉堡内：服务、方向、国家/指南、案例、顾问、Lab、活动、关于。  
- 案例与顾问 **不得** 藏超过二级（原则 #5/#4）。  
- 底栏始终可及，但不侵入第一屏品牌构图（任务书硬约束）。

### 3.3 页脚信息架构

| 列 | 链接 |
|---|---|
| 服务 | 三线 + 流程费用 |
| 方向 | 五垂直 |
| 资源 | Lab / 案例 / 顾问 / 指南 / 活动 |
| 信任 | 主体、ICP、隐私、条款、免责、投诉/监督、年龄声明 |

**依据：** 原则 #13。

## 5. 文字线框（关键模板）

### 5.1 T-HOME 首页

```
┌──────────────────────────────────────────────┐
│ [品牌名 英雄级]                               │
│ 一句定位（垂直深耕 · 顾问可见 · 执行透明）      │
│ 一句支持（给大陆家庭的可核对规划）             │
│ [免费评估]  [看案例]     （微信入口不挡构图）   │
│ ████████ 全宽主视觉（真实场景/工作氛围） ████ │
└──────────────────────────────────────────────┘
§ 为何可信（三句：顾问可见 / 难点案例 / 流程边界）— 无统计条堆砌
§ 五垂直入口（文字+轻图标，非卡片墙）
§ 精选案例 2–3（可点列表项）
§ 顾问条 2 人横滑
§ Lab 入口一行：「先自检，再评估」
§ 家长可读：服务边界 + 链流程费用
§ 活动预告（可空态「下场即将公布」）
§ 终区 CTA：免费评估 + 企微
```

**禁忌：** 第一屏仪表盘、多国入口抢戏、英雄区卡片拼贴。依据原则 #9。

### 5.2 T-TRACK 垂直页

```
面包屑：首页 > 留学方向 > {赛道}
H1 + 答案块（120 字结论）
主 CTA「评估我的背景」| 次「看时间表」| 企微
§ 服务谁 / 不服务谁
§ 时间轴（12–18 月倒推）
§ 硬条件框架 + 例外
§ 费用框架（学费/生活/服务逻辑，标年份）← 家长块
§ 方法论 3 点
§ 案例 2–3（像我）
§ 推荐顾问
§ FAQ 6–10 + Schema
§ 下一站（国家页 / Lab / 评估）
§ 短表嵌入
```

### 5.3 T-CASE-D 案例详情

```
脱敏标题 + 结果层次标签
结构固定：
  背景 → 目标 → 申请难点 → 策略 → 执行 → 结果
顾问链接 | 「同类规划」CTA | 「指定该顾问」
免责：个案不代表概率；可下架说明
家长：免责 + 链流程边界
下一站：同赛道案例 / 垂直页
```

### 5.4 T-LAB-T 工具结果页

```
结果摘要（可复制/可选保存）
口径说明（年份、假设、非录取意见）
DIY 下一步 → Playbook / 清单
专业介入信号 → [预约解读] [加企微]
禁止：未出结果前死表单；伪匹配百分比
```

### 5.5 T-COMM Feed（P1）

```
未登录：频道介绍 + 精选摘要 1–2 句 + 登录引导 + 活动预告
已登录：问答/经历流 + 标签筛 + 发帖（公约勾选）
帖底弱 CTA「仍不确定？预约评估」— 不遮挡阅读
noindex；不进 sitemap/llms.txt
```

## 7. 关键用户旅程（≥5）

### J1 高意图英研搜索 → 评估

```
百度「双非英研费用 2026」
  → /guides/... 答案块
  → 下一站 /tracks/uk-pg
  → 费用框架（家长转发）
  → 短表 or 企微
  → 15min 首触
```
验收：UTM 可见；track=uk-pg；原则 #11/#2。

### J2 家长主导低龄

```
朋友转介绍 → /tracks/k12
  → 监护/安全/费用总账块
  → /process-fees 不含项
  → /about/trust 投诉入口
  → tel: 或企微
```
验收：家长三件套齐全；原则 #1/#13。

### J3 学生逛案例找像我

```
/cases 筛：港新 + 双非
  → 详情读难点
  → 指定顾问评估
  → preferred_advisor 入库
```
验收：原则 #4/#5；AC-02。

### J4 Lab 自检再转化

```
导航 Lab → 时间轴工具
  → 结果四段 → 介入信号
  → 预约解读（预填方向）
  → 感谢页加强微
```
验收：Lab §4；无伪概率；原则 #8。

### J5 社媒切片回链

```
小红书案例切片 + UTM
  → /cases/{slug} SoT
  → 评估 or 微信
  → 后台 utm_source=xiaohongshu
```
验收：原则 #15。

### J6 社区回访（P1）

```
活动预告 L0 → 登录
  → AMA 全文 → 收藏话题
  → 弱出口评估（可选）
```
验收：未登录无全文；社区门禁。

### J7 对比选线

```
/services/compare
  → 看懂适合信号
  → /book「帮我选」
```
验收：对比表移动可横滑或定义列表。
