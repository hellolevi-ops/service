## 2. Primitives 约定（摘要）

| 组件 | 状态 | a11y |
|---|---|---|
| Button | default / hover / active / loading / disabled | `:focus-visible` 环；loading 时 `aria-busy` |
| Input | default / focus / error / disabled | `label` 关联；`aria-invalid` |
| Checkbox | unchecked / checked / error | 隐私同意必须可键盘操作 |
| Dialog/Drawer | open/close | Esc 关闭；焦点陷阱；微信内优先 Drawer |

点击域移动 ≥44px（PRD NFR）。

## 4. 业务组件规格

### 4.1 LeadForm

**对应：** PRD §8.3；US-NAV-01；原则 #3/#14。

| 项 | 说明 |
|---|---|
| 用途 | 渐进留资；与加微并列不互斥 |
| Variants | `short` \| `book` \| `tool` \| `event` |

**内容槽 / Props**

```ts
type LeadFormProps = {
  variant: 'short' | 'book' | 'tool' | 'event'
  track?: TrackSlug
  preferredAdvisorId?: string
  eventSlug?: string
  labTool?: string
  privacyVersion: string
  submitLabel?: string // 默认「预约免费评估」
  onSuccess?: (leadId: string) => void
}
```

**字段**

| 层 | 字段 | 必填 |
|---|---|---|
| 短表 | 称呼、手机、意向方向、隐私同意 | 是（≤4） |
| 选填 | 微信同号、入学年、学历阶段 | 否 |
| book/tool 展开 | 均分区间、语言、预算、方便时段、preferred_advisor | 否 |

隐藏：`website` 蜜罐；UTM 从 sessionStorage 注入。

**状态**

| 状态 | UI |
|---|---|
| 默认 | 清晰 label；同意未勾选不可提交 |
| 校验错 | 字段下红字；焦点移至首错 |
| 加载 | 按钮 loading，防双提交 |
| 成功 | 内联成功或跳转 `/thank-you`；强化 WeComDock |
| 限流错 | 「提交过于频繁，请稍后再试」 |
| 空 | — |

**a11y：** 错误与 `aria-describedby`；同意框可 Tab。  
**埋点：** `form_start` / `form_submit_success` / `form_submit_fail`（variant, track）。

### 4.2 WeComDock

**对应：** 原则 #2；H。

| Props | qrUrl, wechatId?, advisorName?, placement: `inline`\|`drawer`\|`footer` |
|---|---|
| 状态 | 默认；二维码加载失败→显示微信号+复制；复制成功 Toast |
| a11y | img alt=`微信咨询二维码`；复制按钮有文本 |
| 埋点 | `wechat_click` / `wechat_copy`（page, placement） |

---

### 4.3 StickyMobileDock

**对应：** PRD §5.2；原则 #2/#9。

| 槽 | 评估→/book 或打开 LeadForm drawer；微信→WeComDock；电话→`tel:` |
|---|---|
| 状态 | 默认固定；键盘弹起时上移或暂隐（防遮挡输入） |
| 埋点 | `cta_click` location=`mobile_dock`；`phone_click` |

不覆盖英雄区品牌构图：仅底部安全区。

### 4.4 AdvisorCard

**对应：** US-ADV-01；原则 #5；启德顾问卡字段启发。

| Props | advisor: {slug,name,photo,years,tracks,methodOneLiner,acceptBooking,caseCount?} |
|---|---|
| 槽 | 头像、姓名、方向 Tag、年限、一句话方法、代表案例链、CTA |
| 状态 | 默认/悬停（列表可交互故允许轻卡片）；`acceptBooking=false`→CTA 禁用「暂不接评估」；加载 Skeleton；空→EmptyState「顾问更新中」 |
| a11y | 姓名为链接文本；图片有 alt |
| 埋点 | `advisor_card_click`；`advisor_cta_click` |

### 4.10 ProcessTimeline

**对应：** 原则 #6；F。

≥5 步；每步：标题、做什么、客户交付物、耗时量级、是否含套餐。  
状态：默认；P1 可展开交互。移动纵向。埋点 `process_step_open`（P1）。

### 4.11 FeeBoundary

## 6. 无障碍基线

- 键盘可完成预约全流程。  
- 信息不只靠 hover（移动无 hover）。  
- 色对比达 AA；错误不只靠颜色。  
- 动效遵循 D7「减少动态」。  
- 社区若用防爬扰乱字体：**不得**作为唯一信息通道（社区说明慎用项）。
