## 0. 共性约束（三套皆遵守）

| 约束 | 来源 |
|---|---|
| 品牌名 = 第一屏主信号 | 任务书；原则 #9 |

## 方案 A「书院研判」

### A.1 意图与客群假设

- **情绪：** 克制、纸感、编辑型、信任优先。  
- **中国区假设：** 家长向主读——稳、专业、少促销；适合中高客单精品与全流程。  
- **对标气质：** 啄木鸟/Crimson 的「咨询室」感，但更纸媒编辑而非藤校炫富墙。

### A.2 情绪板

宣纸灰底、墨绿点睛、石墨标题、真实顾问工作照与书桌器物、轻微纤维纹理、大量呼吸感留白但**信息可扫读**（非欧美冷淡空站）。

### A.3 色板（CSS 变量）

```css
:root[data-theme="academy"] {
  --bg: #F3F1EC;
  --bg-elevated: #FFFdf8;
  --ink: #1C2421;
  --ink-muted: #5C6560;
  --brand: #1F4D3A;          /* 墨绿 */
  --brand-hover: #163829;
  --accent: #9A6B2F;         /* 暖铜，克制点缀，非假金奖杯 */
  --line: #D9D3C7;
  --success: #2F6B4F;
  --danger: #8F2F2F;
  --focus: #1F4D3A;
}
```

### A.4 字体配对

| 角色 | 建议 | 说明 |
|---|---|---|
| Display | **Source Han Serif SC / 思源宋体**（或 Noto Serif SC） | 品牌名、H1 |
| Body | **Source Han Sans SC / 思源黑体** | 正文、UI |
| Mono（Lab 少用） | IBM Plex Mono 子集 | 仅工具结果数字 |

自托管子集；`font-display: swap`。

### A.5 摄影 / 质感

- 自然光室内、真实对话与材料桌面；忌握手假笑图库。  
- 背景：极弱纸纹或纵向柔和渐变（暖灰→米白），非平面一块色。  
- 主视觉全宽，无圆角卡片镶嵌。

### A.6 组件圆角与密度

| Token | 值 |
|---|---|
| radius-sm | 4px |
| radius-md | 8px |
| 列表卡片 | 仅 Case/Advisor 用浅底+细线，无重阴影 |
| 间距密度 | 舒适偏松；段落行高 1.7 |
| 阴影 | 几乎不用；悬停仅线色变化 |

### A.7 首页第一屏草图

```
[品牌名 · 宋体大号]
垂直深耕的留学规划工作室
给家庭可核对的路径、顾问与边界
[预约免费评估]  [浏览案例]
────────────────────────────────
全宽：顾问与家长围桌沟通的真实照片（边缘到边缘）
右下角不放角标；微信入口在顶栏工具区 / 底栏
```

### A.8 禁忌清单（本方案）

- 大红促销条、倒计时、奖杯墙  
- 过度花纹导致微信内加载失败的超大图  
- 把宋体用在密集 UI 表格  

### A.9 适合

全站主皮；家长决策重、客单中高、信任优先的工作室。

## 方案 B「赛道工作室」

### B.1 意图与客群假设

- **情绪：** 当代品牌、锋芒清晰、垂直专家。  
- **中国区假设：** 学生向主读——有态度但仍忌土促销；适合美本/艺术等强身份赛道投放页。  
- **对标气质：** Crimson 品牌感本地化，去藤校数字炫耀。

### B.2 情绪板

深青墨底或日间高对比、电青绿点缀、几何分割、强第一屏排版、摄影偏纪实校园/作品集细节。

### B.3 色板

```css
:root[data-theme="studio"] {
  --bg: #0E1518;
  --bg-elevated: #172126;
  --ink: #E8EEF0;
  --ink-muted: #9AA8AE;
  --brand: #3DB8A0;          /* 海沫青 */
  --brand-hover: #56C9B3;
  --accent: #E8C547;         /* 信号黄，少用 */
  --line: #2A383E;
  --success: #3DB8A0;
  --danger: #E57373;
  --focus: #3DB8A0;
}
/* 日间变体（垂直页默认用日间，避免家长误判「夜店风」） */
:root[data-theme="studio-day"] {
  --bg: #F4F7F8;
  --bg-elevated: #FFFFFF;
  --ink: #122026;
  --ink-muted: #5A6A70;
  --brand: #0F6E62;
  --brand-hover: #0C5A50;
  --accent: #C45C26;         /* 铁锈橙点缀，非陶土奶油套路 */
  --line: #D2DCE0;
  --focus: #0F6E62;
}
```

**全站若用 B，默认 `studio-day`**；深色仅用于艺术垂直/活动皮肤。

### B.4 字体

| 角色 | 建议 |
|---|---|
| Display | **Smiley Sans / 得意黑** 或 **Alibaba PuHuiTi 2.0** 粗体（品牌/H1） |
| Body | **IBM Plex Sans SC** 或 思源黑体 |

### B.5 摄影 / 质感

斜线分割、局部大字号重叠照片边缘、颗粒轻微；主视觉仍全宽。忌霓虹紫光。

### B.6 圆角与密度

| Token | 值 |
|---|---|
| radius | 2–6px（偏利落） |
| 密度 | 中高；列表更紧 |
| 阴影 | 单层极淡 |

### B.7 第一屏草图

```
[品牌名]
美本 · 路径写清楚的工作室
少口号，多方法
[评估我的背景]  [方法论 Lab]
全宽：学生作品/校园纪实裁切 + 大号赛道名水印（低对比）
```

### B.8 禁忌

- 深色主题堆发光与玻璃拟态  
- 第一屏放 Offer 数字墙  
- 圆角药丸 CTA 成串  

### B.9 适合

垂直投放着陆、艺术/美本；作**季节/活动皮肤**优于作家长主站。

## 方案 C「工具实验室」

### C.1 意图与客群假设

- **情绪：** Lab/工具感、模块化、信息密度、方法论可见。  
- **中国区假设：** 强调自助与清晰感；顾问是升级路径；适合硕博效率型学生。  
- **对标气质：** 前途工具矩阵的「有用」，去 AI 蓝紫皮肤。

### C.2 情绪板

冷灰蓝工作台、网格、等宽数字、面板分区、示意图多于情怀大图。

### C.3 色板

```css
:root[data-theme="lab"] {
  --bg: #E9EEF2;
  --bg-elevated: #F7FAFC;
  --ink: #1A2330;
  --ink-muted: #5B6777;
  --brand: #245B8A;          /* 钢青 */
  --brand-hover: #1B476C;
  --accent: #D97706;         /* 琥珀，表示「结果/注意」 */
  --line: #C5D0DA;
  --grid: rgba(36,91,138,0.08);
  --success: #1F7A5C;
  --danger: #B42318;
  --focus: #245B8A;
}
```

### C.4 字体

| 角色 | 建议 |
|---|---|
| Display | **Sarasa Gothic SC / 更纱黑体** 或 Source Han Sans 粗 |
| Body | Source Han Sans SC |
| Data | JetBrains Mono / IBM Plex Mono 子集 |

### C.5 摄影 / 质感

示意图、流程图、轻微网格底；摄影用「手写清单/白板」实拍。全宽英雄可以是抽象工作台纹理 + 品牌字，但仍需一张真实锚点图（原则：真实视觉锚）。

### C.6 圆角与密度

| Token | 值 |
|---|---|
| radius | 6px 面板 |
| 密度 | 高；适合 Lab/工具页 |
| 模块 | 可分栏，但首页仍禁止仪表盘第一屏 |

### C.7 第一屏草图

```
[品牌名]
申请实验室 — 先把路径算清楚
[打开 Lab]  [预约解读]
全宽：实拍工作台/时间轴纸质道具
下方才是工具矩阵（第二屏）
```

### C.8 禁忌

- 第一屏直接 8 宫格工具墙  
- 伪「匹配度 97%」大字  
- 终端绿字黑客梗（不专业） |

### C.9 适合

Lab 频道皮肤、工具结果页；不宜单独作为家长信任主站唯一皮。

## 方案对比与推荐

| 维度 | A 书院研判 | B 赛道工作室 | C 工具实验室 |
|---|---|---|---|
| 家长信任 | ★★★★★ | ★★★ | ★★★ |
| 学生锋芒 | ★★★ | ★★★★★ | ★★★★ |
| 精品客单 | ★★★★★ | ★★★★ | ★★★ |
| Lab 表达 | ★★★ | ★★★ | ★★★★★ |
| 微信内稳妥 | ★★★★★ | ★★★★（日间） | ★★★★ |
| 实现风险 | 低 | 中（深色慎用） | 中（易做成后台感） |

### 推荐结论

**主风格采用方案 A「书院研判」。**

**理由（对中国家长/学生）：**

1. 大陆共同决策中家长出资权重高，A 的纸感与克制最贴近「专业、稳、有温度」原则（中国区 §6、原则 #12）。  
2. 差异化「小而深、执行透明」需要编辑型信息架构气质，而非促销或炫酷皮肤（调研 §6.3）。  
3. 微信内置浏览器下，浅色纸感与压缩摄影更易保 LCP（原则 # 设备章）。  
4. B、C 不废弃：B 作美本/艺术垂直与招生季皮肤；C 作 `/lab` 频道局部主题（同品牌色相衍生，不换品牌名）。

### 季节皮肤策略

| 场景 | 皮肤 |
|---|---|
| 默认全站 | A |
| 美本早申季投放着陆 | B（studio-day） |
| Lab 工具结果页 | A 全局 + C 面板组件 token |
| 年终活动 | A + 有限 accent，不改红促销 |
