## 1. 设计目标

面向中国大陆**学生 + 家长**共同决策场景，交付一套可开发落地的留学工作室官网设计：

1. **专业表达对齐头部六层骨架**（国家×学历×产品、顾问+案例、生命周期、多通道转化、工具、内容），体量保持小而深。  
2. **微信 / 企微第一转化**，表单并列；主 CTA = 免费评估/规划。  
3. **差异化可感知：** 顾问可见、执行透明、垂直方法论、费用边界可读——不用低价或包录证明专业。  
4. **Lab 证明经验、社区做留存**，二者均不替代服务骨架。  
5. **技术衔接 HK 现网** Next / PG / Redis / Directus，增量修订而非推倒重来。

## 4. 多套方案对比结论

### 4.1 视觉三案

| 方案 | 一句话 | 结论 |
|---|---|---|
| A 书院研判 | 纸感编辑、信任优先 | **主推荐** |
| B 赛道工作室 | 当代锋芒、垂直投放 | 季节/垂直皮肤（日间） |
| C 工具实验室 | 模块化 Lab 感 | `/lab` 局部面板 |

详述见 [05_视觉风格方案.md](./05_视觉风格方案.md)。

### 4.2 推荐组合拳（风格 × 组件 × 分期）

```
主风格 A「书院研判」
  × Domain 组件包（D5）
  × P0：骨架 + Lab 同期 + 转化三通道
  × P1：社区主航道 + 工具增强 + 企微路由
  × 皮肤：B→美本/艺术着陆；C→Lab 结果面板
  × 技术：HK Next/PG/Redis/Directus 增量（D3）
```

| 分期 | 设计焦点 |
|---|---|
| P0 | 六层骨架页模板 + LeadForm/WeCom + Lab 壳 + Token A |
| P1 | 社区 Gate/Feed、Lab 匹配/费用、顾问筛选强化 |
| P2 | 门户进度、个性化（克制） |
