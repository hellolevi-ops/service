## 6. 选型建议（定稿前）

1. **主标**：采用 `mark.svg` 几何三叶（与「青藤 / Ivy」语义一致，可商用无版权纠葛）。  
2. **色**：沿用现网深蓝 Ivy Token；若切回文档「书院研判」墨绿，把 SVG 中 `#0F172A` 换成 `#1F4D3A`、琥珀改 `#9A6B2F`。  
3. **英雄**：优先 `campus-dusk`；避免握手假笑图库。  
4. **预览 PNG**：仅供选型；上线路径用 SVG + 摄影 JPG。
