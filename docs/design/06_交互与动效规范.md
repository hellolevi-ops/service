## 1. 动效原则

| 原则 | 说明 | 依据 |
|---|---|---|
| 服务反馈 | 动效只解释状态变化与空间关系 | PRD §10.5 |
| 预算克制 | 每模板有意动效 **2–3 处**，其余瞬时 | 任务书 |
| 可关闭 | 尊重 `prefers-reduced-motion` | a11y |
| 禁焦虑 | 无恐吓倒计时、无伪造热度跳动 | 原则 #12；红线 |

## 2. 时长与缓动 Token

```css
:root {
  --ease-out: cubic-bezier(0.22, 1, 0.36, 1);
  --ease-standard: cubic-bezier(0.4, 0, 0.2, 1);
  --dur-1: 120ms;   /* 按钮/颜色 */
  --dur-2: 200ms;   /* 面板展开 */
  --dur-3: 320ms;   /* 抽屉/结果揭示 */
  --dur-4: 480ms;   /* 仅英雄入场，可关 */
}
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

| 类型 | 时长 | 说明 |
|---|---|---|
| 颜色/透明度 | 120ms | hover |
| 高度展开 | 200ms | FAQ、流程步骤 |
| 抽屉/Modal | 280–320ms | 微信内优先自底抽屉 |
| 结果揭示 | 320ms | Lab 结果区 fade+轻微上移 |
| 页面入场 | ≤480ms 一次 | 仅品牌/英雄；可关 |

## 3. 场景规范

### 3.1 站内飞轮反馈

| 交互 | 行为 |
|---|---|
| 答案块进入视口 | 可选 1 次轻微高亮边线（200ms）；触发 `answer_block_view` |
| 下一站点击 | 涟漪或颜色反馈 120ms；即时跳转，不故意延迟 |
| 清晰小结勾选 | 本地勾选动画 120ms；正向微反馈 ✓ |
| 阅读进度 | 顶栏细线进度；减少动态时改为静态百分比 |

**禁止：** 未读完弹全屏留资；退出意图最多温和一次（PRD §6.8）。

### 3.2 表单 LeadForm

| 阶段 | 交互 |
|---|---|
| 聚焦 | 边框品牌色；无跳动 |
| 校验失败 | 字段抖动**禁止**；改用红字+`aria-live` |
| 提交中 | 按钮 spinner；防重复 |
| 成功 | 短 Toast 或内联成功 → 展示 WeComDock（抽屉滑入 320ms） |
| 蜜罐命中 | 静默成功态假反馈或不跳转后台（对用户无感） |

渐进展开第二层字段：手风琴 200ms，默认折叠。

### 3.3 微信 / 企微唤起

| 环境 | 行为 |
|---|---|
| 微信内置浏览器 | 点击「微信」→ 底部 Drawer 展示二维码（长按识别）；提供复制微信号备份 |
| 系统浏览器移动 | Drawer 二维码 + 「打开微信」文案指引（不承诺 URL Scheme 100% 成功） |
| 桌面 | 弹层二维码；旁注「手机扫码」 |

**禁止：** 未交互自动全屏弹码；连环弹层（不对齐金吉列密度）。

### 3.4 社区登录墙

| 步骤 | 交互 |
|---|---|
| 未登录点全文 | 内容区模糊/截断 → Gate 面板上移；埋点 `community_gate_hit` |
| 登录成功 | Gate 淡出；正文展开 200ms |
| 发帖 | 公约勾选门禁；提交后「审核中」态 |

转化出口贴文末，**不**在阅读中途插屏。

### 3.5 Lab 结果揭示

```
输入完成 → [生成] 
  → 骨架屏 200–600ms（真实计算可短则短）
  → LabResultPanel 四段依次 fade-in（每段间隔 ≤80ms，总 ≤320ms）
  → 介入信号区次 CTA 可用
```

**禁止：** 故意延长等待制造焦虑；未出任何结果先锁表单；大数字「匹配度」跳动。

保存方案：可选；点击后才出短表。

## 4. 页面级动效预算示例

| 模板 | 允许的有意动效 |
|---|---|
| 首页 | ① 英雄图轻微 KenBurns **或** 渐显（二选一）② CTA hover ③ 案例列表悬停线 |
| 垂直页 | ① 答案块入视 ② FAQ 展开 ③ 底栏出现 |
| Lab 工具 | ① 提交 loading ② 结果揭示 ③ DIY 链接 hover |
| 案例详情 | ① 锚点切换 ② CTA |
| 社区 | ① Gate ② 列表加载 skeleton |

## 5. 手势与移动

- 底栏：安全区 padding；键盘弹出时避开遮挡（resize/visualViewport）。  
- 抽屉高度 ≤ 85vh；可下拉关闭。  
- 横向滑：仅顾问条/对比表；展示滑指示。  
- 点击域 ≥44px。

---

## 6. 减少动态

当 `prefers-reduced-motion: reduce`：

- 关闭英雄 KenBurns、交错入场、数字滚动。  
- 保留必要的显示/隐藏瞬时切换。  
- Lab 结果一次全部出现，无交错。

设置页（可选 P1）提供「关闭动效」本地开关。

---

## 7. 禁止项清单（交互评审一票否决）

1. 恐吓倒计时 / 「名额仅剩 N」动态数字  
2. 伪造「正在咨询」滚动热度  
3. 强制连环弹层阻断阅读  
4. 抖动惩罚校验  
5. 未出 Lab 结果强制留资  
6. 社区阅读中全屏评估插屏  
7. 自动播放有声视频  
8. 依赖 hover 才能看见关键费用/不含项  

---

## 8. 与埋点的关系

动效完成不单独发事件；业务事件见 D5。注意：不要为凑动画延迟 `form_submit` 响应。
