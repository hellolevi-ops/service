## 1. 开发原则

1. **实现推荐视觉方案**（见设计总纲 §4 推荐结论；默认「书院研判 / academy」除非总纲写明其他）。接入 `08_设计Token.css`。  
2. **P0 门禁对齐 PRD**：国家×学历×产品 IA、案例可筛、顾问可指定、流程费用、微信+表单、AnswerBlock+下一站、评估工具最小集、线索入库+通知。  
3. **微信第一**：`WeComDock` / 移动底栏；感谢页引导加企微。  
4. **线索不失**：`POST /api/leads` 先写 PG，Outbox 发邮件；限流用 Redis。  
5. **SEO/AEO**：SSR/SSG、sitemap、JSON-LD、`llms.txt`、答案块。  
6. **勿动** 现有 `jq-factor-receiver` / nginx:9443 业务。官网 nginx 另配 server 或新 port。  
7. **密钥不入库**：`.env.local` 仅服务器；本地开发用 SSH 隧道或独立 `.env.example`。  
8. 代码可在服务器直接开发，或本地开发后 rsync/git 同步到 `/data/studyabroad/apps/web`——**以服务器可运行的生产构建为准**。
